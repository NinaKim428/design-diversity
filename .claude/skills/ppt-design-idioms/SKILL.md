# PPT Design Idioms — 프레젠테이션 디자인 관용

ppt-pack-curator가 PPT 스타일을 팩으로 증류할 때 따르는, 슬라이드 매체 고유의 지식.

## PPT가 웹과 다른 점

- **고정 캔버스.** 16:9(13.33×7.5in) 고정. 반응형이 없으니 그리드·여백을 절대값으로 못박는다.
- **슬라이드 단위 구성.** 한 슬라이드 = 한 메시지. 스크롤이 아니라 장면 전환.
- **발표 거리 가독성.** 화면에서 멀리 본다 — 본문 24pt+, 제목 36pt+, 한 슬라이드 글자 수 제한.
- **차트·다이어그램이 주역.** 웹보다 데이터 시각화 비중이 크다. 차트 스타일이 팩 정체성의 핵심.

## 슬라이드 타입 위계

팩의 prompt.md는 최소 이 타입들에 대한 지시를 담는다:
- **표지** — 제목 타이포 스케일, 배경 처리, 메타 정보 배치.
- **본문(불릿/스테이트먼트)** — 텍스트 위계, 불릿 vs 비불릿, 여백.
- **차트/데이터** — 차트 색·축·격자선·레이블 스타일.
- **간지/섹션** — (선택) 챕터 구분 슬라이드.
- **결론/마무리** — (선택).

## 검증 가능한 지시로 옮기기

diversity-qa가 시각 대조하므로 모호어는 통과하지 못한다. 각 항목을 절대값·개수·비율로 적는다:

| 모호 (금지) | 검증 가능 (사용) |
|---|---|
| "깔끔한 레이아웃" | "좌우 여백 각 0.8in, 헤더바 높이 캔버스의 12%, 12열 그리드" |
| "강조 색 사용" | "강조색 1개만, 표지·차트 핵심 계열에만, 텍스트엔 무채색" |
| "읽기 좋은 폰트" | "제목 40pt/Bold, 본문 24pt/Regular, 행간 1.3, 슬라이드당 6줄 이하" |
| "세련된 차트" | "막대 차트만, 격자선 제거, 값 레이블 직접 표기, 색은 강조색 단색조" |

## 차트·데이터 시각화 — 전문성의 시험대

발표 자료에서 차트는 가장 자주 등장하면서 가장 자주 망가지는 요소다. 아마추어 차트 하나가 덱 전체의 신뢰도를 떨어뜨린다. 모든 PPT 팩의 prompt.md는 차트를 **별도 항목으로 구체적으로** 규정해야 한다 — "막대 차트 사용" 한 줄로는 부족하다.

**데이터 잉크 원칙 (Tufte).** 데이터를 직접 나타내지 않는 잉크를 최소화한다:
- 격자선 제거(또는 y축 주요 눈금만 헤어라인 0.5pt). 차트 테두리 박스 제거. 배경 채움 제거.
- 축선은 헤어라인이거나 아예 없앤다. 눈금 라벨은 최소 개수만(예: 0과 최댓값).
- 범례 대신 **직접 레이블링** — 계열 이름을 막대·선 끝에 직접 붙인다. 범례 박스는 계열 4개 이상일 때만.

**값 레이블.** 막대·꼭짓점 위에 값을 직접 표기한다(축에서 눈으로 읽게 하지 않는다). 숫자는 본문보다 작게(예: 14~16pt), 굵게, 일관된 자릿수·단위. 숫자에는 탭형 라인(tabular) 정렬을 쓴다.

**색.** 데이터 색은 팩 강조색 1색의 명도 단계(연→진) 또는 의미색(증가=긍정색 / 감소=경고색)만. 계열마다 다른 색을 무지개로 칠하지 않는다. 강조할 막대 1개만 강조색, 나머지는 무채색 — 이것이 컨설팅·IR 차트의 핵심 기법이다.

**차트 타입 매칭.** 비교=세로/가로 막대, 추세=라인 또는 옅은 면적, 비중=도넛(조각 3개 이하, 중앙에 핵심 수치) 또는 100% 누적 막대 1개, 구성변화=기울기 그래프. 파이차트 조각 5개 이상·3D·도넛 다중 금지.

**정밀 렌더링.** 차트는 SVG로 정확하게 그린다(div 블록 막대로 대충 그리지 않는다):
- 막대 폭:간격 비율을 명시(예 막대 : 간격 = 3 : 2). 모든 막대 정렬·기준선 0 정확히.
- 모서리는 각지게(둥근 막대는 해당 팩 스타일이 명시적으로 요구할 때만). 안티앨리어싱된 깔끔한 엣지.
- 축 기준선은 반드시 0에서 시작(잘린 y축 금지 — 왜곡).

**차트도 팩의 시각 언어를 입는다.** 차트가 팩과 따로 노는 것이 "허접함"의 정체다:
- 컨설팅·IR 팩 — 맥킨지식: 무채색 막대 + 강조 1막대, 액션 타이틀, 출처 각주, 단위 명기.
- 에디토리얼·신문 팩 — 세리프 캡션, 룰 라인, 잉크빛 단색 데이터.
- 브루탈·멤피스 팩 — 두꺼운 검정 보더 + 평면 원색 채움, 거친 정렬.
- 다크테크·인포그래픽 팩 — 발광 데이터 라인, 모노 수치 라벨, 미니 KPI 카드.
- 럭셔리·미니멀 팩 — 헤어라인 1pt 라인 차트, 광활한 여백, 골드/잉크 단색.

prompt.md의 "적용 예" 차트 항목에 위를 팩별 절대값(막대 폭, 레이블 pt, 데이터 색 hex, 축 처리)으로 못박는다.

## 팩 정체성을 과장하라

다양성이 목적이다. 각 팩은 자기 스타일을 끝까지 민다:
- 컨설팅 팩 — 더 빽빽한 그리드, 더 작은 캡션, 출처 각주 의무화.
- Keynote 미니멀 팩 — 슬라이드당 단어 수를 극단적으로 줄이고 풀블리드 이미지.
- 브루탈/멤피스 팩 — 비대칭, 거친 도형, 원색 충돌.
baseline(밋밋한 기본 PPT)과 한눈에 구별되지 않으면 실패다.

## "하지 말 것" 단서 (Claude 기본 회귀 차단)

PPT에서 Claude가 기본값으로 흔히 회귀하는 것 — 팩 성격에 맞게 prompt.md의 "하지 말 것"에 명시:
- 모든 슬라이드 중앙 정렬 / 균일한 둥근 모서리 박스 / 슬라이드마다 같은 레이아웃 반복.
- 3D·그림자 남발 차트 / 무지개색 차트 / 격자선·범례 과다.
- 이모지 불릿 / 클립아트 / 의미 없는 스톡 아이콘.
- 슬라이드를 글로 가득 채우기.

## 한국어 슬라이드 주의

한국어 본문은 영문보다 글자 폭이 크다 — 줄당 글자 수와 행간을 한국어 기준으로 지시한다. 폰트는 Pretendard·Noto Sans KR 등 한글 지원 폰트를 기본 또는 대체 폰트로 지정한다.
