# PPT Design Idioms — 프레젠테이션 디자인 관용

ppt-pack-curator가 PPT 스타일을 팩으로 증류할 때 따르는, 슬라이드 매체 고유의 지식.

## PPT가 웹과 다른 점

- **고정 캔버스.** 16:9(13.33×7.5in) 고정. 반응형이 없으니 그리드·여백을 절대값으로 못박는다.
- **슬라이드 단위 구성.** 한 슬라이드 = 한 메시지. 스크롤이 아니라 장면 전환.
- **발표 거리 가독성.** 화면에서 멀리 본다 — 본문 24pt+, 제목 36pt+, 한 슬라이드 글자 수 제한.
- **차트·다이어그램이 주역.** 웹보다 데이터 시각화 비중이 크다. 차트 스타일이 팩 정체성의 핵심.

## 슬라이드 타입 위계

팩의 prompt.md는 최소 이 타입들에 대한 지시를 담는다:
- **표지** — 제목 타이포 스케일, 배경 처리, 메타 정보 배치.
- **본문(불릿/스테이트먼트)** — 텍스트 위계, 불릿 vs 비불릿, 여백.
- **차트/데이터** — 차트 색·축·격자선·레이블 스타일.
- **간지/섹션** — (선택) 챕터 구분 슬라이드.
- **결론/마무리** — (선택).

## 검증 가능한 지시로 옮기기

diversity-qa가 시각 대조하므로 모호어는 통과하지 못한다. 각 항목을 절대값·개수·비율로 적는다:

| 모호 (금지) | 검증 가능 (사용) |
|---|---|
| "깔끔한 레이아웃" | "좌우 여백 각 0.8in, 헤더바 높이 캔버스의 12%, 12열 그리드" |
| "강조 색 사용" | "강조색 1개만, 표지·차트 핵심 계열에만, 텍스트엔 무채색" |
| "읽기 좋은 폰트" | "제목 40pt/Bold, 본문 24pt/Regular, 행간 1.3, 슬라이드당 6줄 이하" |
| "세련된 차트" | "막대 차트만, 격자선 제거, 값 레이블 직접 표기, 색은 강조색 단색조" |

## 팩 정체성을 과장하라

다양성이 목적이다. 각 팩은 자기 스타일을 끝까지 민다:
- 컨설팅 팩 — 더 빽빽한 그리드, 더 작은 캡션, 출처 각주 의무화.
- Keynote 미니멀 팩 — 슬라이드당 단어 수를 극단적으로 줄이고 풀블리드 이미지.
- 브루탈/멤피스 팩 — 비대칭, 거친 도형, 원색 충돌.
baseline(밋밋한 기본 PPT)과 한눈에 구별되지 않으면 실패다.

## "하지 말 것" 단서 (Claude 기본 회귀 차단)

PPT에서 Claude가 기본값으로 흔히 회귀하는 것 — 팩 성격에 맞게 prompt.md의 "하지 말 것"에 명시:
- 모든 슬라이드 중앙 정렬 / 균일한 둥근 모서리 박스 / 슬라이드마다 같은 레이아웃 반복.
- 3D·그림자 남발 차트 / 무지개색 차트 / 격자선·범례 과다.
- 이모지 불릿 / 클립아트 / 의미 없는 스톡 아이콘.
- 슬라이드를 글로 가득 채우기.

## 한국어 슬라이드 주의

한국어 본문은 영문보다 글자 폭이 크다 — 줄당 글자 수와 행간을 한국어 기준으로 지시한다. 폰트는 Pretendard·Noto Sans KR 등 한글 지원 폰트를 기본 또는 대체 폰트로 지정한다.
