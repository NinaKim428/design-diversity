# BCG 익스히빗 덱 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. BCG 익스히빗 덱 — 모든 슬라이드가 좌상단에 `Exhibit N.N` 번호를 달고, 헤더는 answer-first 완결 문장으로 결론을 진술하며, 하단에는 `Source:`/`Note:` 각주 라인이 1px 룰 위에 깔리는 BCG식 근거 중심 컨설팅 덱. 강조는 BCG 그린 단 한 색.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 모든 본문 슬라이드 좌상단에 `Exhibit 3.2` 식 등폭 번호 라벨(그린)이 붙고, 슬라이드는 차트·표가 곧 'Exhibit'이다, (2) 헤더가 제목이 아니라 결론 — "신규 채널이 마진을 4.2%p 끌어올린다" 같은 완결 문장(answer-first), (3) 하단에 항상 1px 룰 + `Source:` / `Note:` 등폭 각주. 강조는 BCG 그린 한 색, 그 외 전부 무채색.

## 색
- 배경 `#FFFFFF` (순백)
- 패널/Exhibit 채움 `#F2F4F3` (아주 옅은 그린그레이)
- 본문 잉크/헤딩 `#1A1A1A`
- 본문 슬레이트 `#5B636E`
- 강조 BCG 그린 `#177B57` — 강조 텍스트·데이터 핵심 계열·Exhibit 라벨에만. 면(배경)으로 쓰지 않는다.
- 헤어라인 룰 `#D6DAD8` (1px)
- 강조색은 그린 1개뿐. 다른 컬러 채색·그라디언트 금지.

## 타이포그래피
- 폰트: 전부 `IBM Plex Sans`(대체 `Inter, Arial, sans-serif`). 등폭 라벨·각주는 `IBM Plex Mono`(대체 `Courier New`). 한글은 `Pretendard`.
- Exhibit 라벨: 11pt / IBM Plex Mono 500 / 자간 +6% / 색 `#177B57`
- 슬라이드 헤더(answer-first 결론): 28pt / IBM Plex Sans 700 / 행간 1.25 / 최대 2줄
- 섹션/Exhibit 부제: 16pt / IBM Plex Sans 600 / 슬레이트
- 본문: 18pt / IBM Plex Sans 400 / 행간 1.4 / 슬라이드당 6줄 이하
- 표·차트 값 레이블: 14pt / IBM Plex Sans 600 / tabular numerals
- 각주(`Source:`/`Note:`): 9pt / IBM Plex Mono 400 / 슬레이트

## 레이아웃 / 그리드
- **엄격 12열 모듈러 그리드(balanced).** 좌우 마진 각 0.58in(=56px @96dpi), 상단 0.5in, 하단 각주용 0.7in 확보.
- 좌상단 고정: `Exhibit N.N` 라벨(그린 등폭 11pt) — 모든 본문/차트/다이어그램 슬라이드에 의무.
- 라벨 아래 28pt answer-first 헤더 — 슬라이드당 takeaway는 단 1개.
- 본문 영역(헤더 하단~각주 상단)은 차트·표·다이어그램이 12열 그리드에 스냅.
- 하단 0.7in: 1px 룰 `#D6DAD8` 위에 `Source: ...` (좌) + `Note: ...` (필요시 우) 등폭 9pt.

## 형태 / 질감
- 모서리 반경 0px. 보더는 1px 헤어라인 `#D6DAD8`만. 그림자·그라디언트 전면 금지.
- Exhibit 패널은 옅은 그린그레이 `#F2F4F3` 채움 또는 헤어라인 윤곽만.
- 아이콘 거의 안 씀 — 쓴다면 1.5pt 가는 라인 단색. 강조는 그린 텍스트 또는 굵기.

## 차트·데이터 시각화 (메코·워터폴 익스히빗 — 무채색 + 그린 강조 1)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 모든 차트는 하나의 'Exhibit'이다.
- **데이터 색:** 막대·세그먼트 기본은 무채색 `#9CA3AC`(연) / `#5B636E`(진) 명도 단계. 강조할 1개 계열·1개 막대만 BCG 그린 `#177B57` 솔리드. 무지개 채색 금지.
- **메코(Marimekko):** 가변폭 100% 누적 막대 — x축 폭이 시장규모, y축 100% 세그먼트. 세그먼트는 무채색 명도, 핵심 1세그먼트만 그린. 폭·높이 비율 정확, 세그먼트 경계 1px 흰선.
- **워터폴:** 시작·종료 막대는 진한 슬레이트 솔리드, 증가분은 그린, 감소분은 무채색 윤곽. 막대 사이 점선 커넥터 0.75pt `#D6DAD8`. 막대 위 델타 값 직접 표기.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0에서 정확히(잘린 y축 절대 금지).
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#D6DAD8`). 차트 테두리 박스 제거. x축선 0.75pt `#5B636E`.
- **값 레이블:** 막대 끝·꼭짓점에 직접 표기. 14pt IBM Plex Sans 600 tabular, 단위·자릿수 일관. 범례 박스 금지 — 계열명을 막대·선 끝에 직접 라벨링.
- **출처:** 차트 하단이 아니라 슬라이드 각주 라인에 `Source:` 등폭 9pt 의무. 단위는 차트 축 옆 또는 헤더에 명기.
- **타입 매칭:** 비교=세로 막대, 추세=1.5pt 폴리라인(면적 채움 없음), 비중=메코 또는 100% 누적 막대 1개, 가치증감=워터폴. 파이·3D·도넛 다중 금지.

## 다이어그램·컴포넌트 (Exhibit 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 흰/그린그레이 셀 + 1px 헤어라인 보더, 커넥터는 1.5pt 가는 화살표 `#5B636E`(화살촉 길이 6px·각도 30°), 강조는 그린 텍스트 또는 좌측 0.1in 그린 솔리드 바, 단계 번호는 0.32in 그린 윤곽 원.
- **프로세스 플로우(임팩트 브리지):** 좌→우 셰브론 또는 사각 노드 4~5단계. 노드 높이 1.0in, 흰 채움 + 1px 헤어라인. 노드 사이 1.5pt 가는 화살표. 각 노드 좌상단 0.32in 그린 윤곽 원에 단계 번호. 현재/핵심 단계만 좌측 0.1in 그린 솔리드 바. 노드 위에 'as-is → to-be' 임팩트 라벨.
- **타임라인:** 수평 축 — 0.75pt 베이스 룰 `#5B636E`, 마일스톤은 0.14in 무채색 원(현재 시점만 그린 솔리드 원). 날짜 라벨은 축 아래 등폭 9pt, 사건 라벨은 축 위 14pt 600.
- **비교(2~3열):** 헤어라인 격자 표. 헤더 행만 그린그레이 `#F2F4F3` 채움 + 600. 우세 열은 헤더에 그린 텍스트 + 좌측 0.1in 그린 바. 수치 셀 우정렬 tabular.
- **매트릭스 2×2:** 0.75pt 헤어라인 십자축. 각 사분면 좌상단에 라벨(14pt 600). 데이터 포인트는 가변 크기 버블 — 무채색 윤곽, 추천 사분면 버블만 그린 솔리드. 축 라벨 바깥 11pt 슬레이트.
- **계층/퍼널:** 폭 비례 사각 적층(피라미드/퍼널) — 무채색 명도 단계, 핵심 단만 그린. 레벨 라벨 우측 14pt. 화살표 없이 폭 변화로 흐름 표현.
- **KPI·스탯 카드:** 흰 셀 + 1px 헤어라인, 좌상단 11pt 슬레이트 라벨, 거대 40pt IBM Plex Sans 700 tabular 수치, 그 아래 14pt 델타(▲ 증가는 그린 / ▼ 감소는 슬레이트). 카드 3~4개 가로 균등.
- **목차/섹션 디바이더/인용:** 목차는 `01`~`NN` 등폭 그린 번호 + 16pt 항목명 + 우측 페이지 번호, 항목 사이 헤어라인. 디바이더는 흰 배경 + 좌측 거대 100pt 그린 윤곽 섹션 번호 + 28pt 섹션명. 인용은 그린그레이 셀 + 좌측 0.1in 그린 바 + 24pt 600 풀쿼트 + 등폭 출처 각주.

## 전환 (PPT)
subtle — Exhibit 라벨과 헤어라인 룰이 200ms ease-out으로 짧게 페이드 인하는 정도만. 슬라이드 본문은 즉시 컷. 슬라이드·바운스·글로우 모션 금지.

## 하지 말 것
- BCG 그린을 면(배경)으로 쓰지 말 것 — 강조 텍스트·데이터 핵심 계열·Exhibit 라벨에만.
- 그라디언트·그림자·둥근 모서리·이모지·클립아트 금지.
- 한 슬라이드에 takeaway 2개 이상 금지 — answer-first 헤더는 단 하나의 결론.
- `Exhibit N.N` 라벨, 하단 `Source:` 각주 라인 생략 금지 — 둘 다 정체성.
- 헤더를 명사구 제목("시장 분석")으로 쓰지 말 것 — 완결 문장 결론으로.
- 차트 회귀: 무지개색, 3D, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
순백 배경. 좌상단 마진 0.58in 지점에 등폭 11pt 그린 `BCG · STRATEGY EXHIBIT DECK`. 캔버스 세로 중앙(상단 42% 지점)에 28pt → 40pt로 키운 700 타이틀 좌측 정렬, 2줄 이내. 그 아래 0.1in 간격으로 16pt 슬레이트 부제 1줄. 하단 0.7in에 1px 헤어라인 룰 풀폭 + 그 아래 등폭 9pt 메타 행(클라이언트명 · 날짜 · `Confidential`). 그린은 상단 라벨에만, 면 채움 없음.

### 02 · 목차 (agenda)
좌상단 `Exhibit 0.1` 그린 라벨 + 28pt 헤더 "본 보고서는 네 가지 질문에 답한다". 본문 영역을 12열 중 좌측 7열에 목차 리스트로 배치 — `01`~`04` 등폭 그린 번호 + 16pt 600 항목명 + 한 줄 요약 14pt 슬레이트, 항목 사이 1px 헤어라인. 우측 5열은 비워 여백. 하단 `Source:` 각주 라인.

### 03 · 핵심 본문 (body, answer-first)
좌상단 `Exhibit 1.1` 라벨. 28pt answer-first 헤더(결론 문장). 본문 영역 좌측 7열: 18pt 본문 3~5줄(불릿 아닌 짧은 단락), 핵심 구절만 그린 600. 우측 5열: 그린그레이 `#F2F4F3` Exhibit 패널에 보조 차트 1개 또는 핵심 수치 KPI 카드. 하단 1px 룰 + `Source:` / `Note:` 각주.

### 04 · 메코·워터폴 차트 익스히빗 (chart)
좌상단 `Exhibit 2.1` 라벨 + 28pt 결론 헤더. 본문 영역 좌측 7열에 메코(가변폭 100% 누적, 무채색 명도 + 핵심 1세그먼트 그린), 우측 5열에 워터폴(시작·종료 슬레이트, 증가 그린, 감소 윤곽, 점선 커넥터). 두 차트 모두 막대 폭:간격 3:2, 베이스라인 0, 값 레이블 14pt 600 직접 표기, 범례 없이 직접 라벨링. 하단 `Source:` 각주 의무.

### 05 · 임팩트 브리지 다이어그램 (diagram)
좌상단 `Exhibit 3.1` 라벨 + 28pt 헤더. 본문 영역에 4단계 사각 노드 임팩트 브리지 — 좌측 'as-is' 상태에서 우측 'to-be'까지, 각 노드 높이 1.0in, 흰 채움 + 1px 헤어라인, 노드 사이 1.5pt 가는 화살표. 각 노드 좌상단 0.32in 그린 윤곽 원 단계 번호. 노드 위에 임팩트 라벨(예 `+1.4%p`)을 그린 600으로. 최종 노드만 좌측 0.1in 그린 솔리드 바. 하단 각주.

### 06 · 2x2 매트릭스 비교 (comparison)
좌상단 `Exhibit 4.1` 라벨 + 28pt 헤더. 본문 영역 중앙에 0.75pt 헤어라인 십자축 2×2 매트릭스. 사분면 좌상단마다 라벨 14pt 600. 데이터 포인트는 가변 크기 버블(무채색 윤곽), 추천 사분면 버블만 그린 솔리드. 축 끝에 11pt 슬레이트 축 라벨(저↔고). 우측 3열은 매트릭스 해석 텍스트 18pt. 하단 `Source:` 각주.

### 07 · 제언·다음 단계 (closing)
좌상단 `Exhibit 5.1` 라벨 + 28pt 헤더 "다음 90일, 세 가지를 실행한다". 본문 영역에 3단계 프로세스 플로우(셰브론 노드, 각 노드 0.32in 그린 윤곽 원 번호, 1.5pt 화살표 커넥터), 각 노드 아래 14pt 실행 항목 + 담당·기한 등폭 라벨. 하단 1px 룰 + 등폭 9pt 컨택트 메타.
