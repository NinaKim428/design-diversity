# 골드만 IR 덱 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 골드만 IR 덱 — 딥 네이비 전면 페이지에 메탈릭 골드 0.5pt 헤어라인이 헤더·섹션·표를 구획하고, 보수적인 트랜지셔널 세리프 헤딩과 등폭 숫자의 재무 표가 권위를 만드는 투자은행 IR·earnings 덱. 우하단에 디스클레이머 풋라인 의무.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드 전면이 딥 네이비 `#0A1A33`, 오프화이트 텍스트 — 보수적 금융 권위, (2) 메탈릭 골드는 0.5pt 헤어라인·라벨에만 — 헤더 밑줄·섹션 구획·표 룰로 가늘게 흐르고 절대 면으로 쓰지 않는다, (3) 헤딩은 트랜지셔널 세리프, 재무 표는 등폭 우정렬. 우하단에 항상 디스클레이머 + 페이지네이션 풋라인.

## 색
- 배경 딥 네이비 `#0A1A33` (전면)
- 패널 네이비 `#1F3A5F`
- 강조 메탈릭 골드 `#C8A24B` — 0.5pt 헤어라인·라벨·차트 핵심 계열에만. 면·버튼 배경으로 절대 쓰지 않는다.
- 텍스트 오프화이트 `#E8E5DE`
- 보조 텍스트 `#9AA6BC`
- 강조색은 골드 1개뿐. 차트 시리즈는 골드 + 오프화이트 + 네이비 명도 단계. 그라디언트·글로우 금지.

## 타이포그래피
- 폰트: 헤딩 `Source Serif 4`(트랜지셔널 세리프, 대체 `Georgia, "Times New Roman", serif`). 본문·숫자 `Inter`(대체 `Arial, sans-serif`). 한글 헤딩은 `Pretendard`(굵게), 본문도 `Pretendard`.
- 슬라이드 헤딩: 26pt / Source Serif 4 600 / 자간 0 / 오프화이트
- 섹션 라벨(골드): 11pt / Inter 500 / 자간 +8% / 대문자 / 색 골드
- 본문: 17pt / Inter 400 / 행간 1.4 / 슬라이드당 6줄 이하
- 재무 표 헤더: 11pt / Inter 600 / 대문자 / 자간 +6%
- 재무 표 숫자: 14pt / Inter 400 / tabular numerals / 우정렬
- KPI 대형 수치: 40pt / Source Serif 4 600 / tabular 느낌
- 디스클레이머 풋라인: 8pt / Inter 400 / 색 보조 텍스트

## 레이아웃 / 그리드
- **엄격 12열 그리드(balanced).** 좌우 마진 각 0.65in, 상단 0.55in, 하단 0.75in(풋라인 확보).
- 슬라이드 상단: 26pt 세리프 헤딩 + 그 아래 0.5pt 골드 헤어라인 풀폭(헤더 구획선).
- 좌상단 또는 헤더 위에 11pt 골드 섹션 라벨(대문자).
- 본문 영역은 12열 그리드 — 재무 표·차트가 스냅. 표는 등폭 숫자 우정렬.
- 우하단 풋라인: 0.5pt 골드 헤어라인 위에 디스클레이머(좌, 8pt) + 페이지 번호(우, 8pt). 모든 슬라이드 의무.

## 형태 / 질감
- 모서리 반경 0px. 보더는 0.5pt 골드 헤어라인 또는 1px 네이비 룰. 그림자·그라디언트·글로우 전면 금지.
- 패널은 네이비 `#1F3A5F` 채움 — 골드는 절대 면으로 쓰지 않는다.
- 골드 헤어라인이 구획 장치(헤더 밑줄·섹션 분리·표 룰). 아이콘 거의 안 씀 — 쓴다면 1pt 가는 라인 골드 단색.

## 차트·데이터 시각화 (재무 익스히빗 차트 — 골드 + 네이비 명도)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). IR earnings 차트 — 보수적, 등폭 숫자, 출처 각주.
- **데이터 색:** 차트 시리즈는 골드 `#C8A24B` + 오프화이트 `#E8E5DE` + 네이비 명도 단계 `#1F3A5F`/`#3A5A85`만. 강조 1계열만 골드. 무지개 채색 금지.
- **다년 추이 라인:** 1pt 폴리라인, 핵심 시리즈만 골드, 비교 시리즈는 오프화이트. 마커는 0.1in 작은 원. 면적 채움 없거나 아주 옅은 골드 8% 채움.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0에서 정확히(잘린 y축 절대 금지 — 재무 왜곡).
- **데이터 잉크 최소화:** 격자선은 y축 주요 눈금 2~3개 0.5pt `#1F3A5F`만. 차트 테두리 박스 제거. 축선 0.75pt `#3A5A85`.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 14pt Inter 400 tabular 우정렬, 단위·자릿수·통화 일관(예 `$M`·`%`). 범례 박스 금지 — 시리즈명 라인·막대 끝에 직접 라벨링.
- **재무 표:** 등폭 숫자 우정렬, 헤더 행만 11pt 대문자 + 하단 0.5pt 골드 룰. 행 사이 1px 네이비 룰. 합계 행은 위 0.5pt 골드 룰 + 굵게.
- **출처:** 차트 하단 좌측 9pt Inter `#9AA6BC` 출처·기준일·통화 각주 의무.
- **타입 매칭:** 추세=다년 라인, 비교=세로 막대, 비중=100% 누적 막대 또는 도넛 1개. 파이 다중·3D·도넛 다중 금지.

## 다이어그램·컴포넌트 (IR 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 네이비 패널 `#1F3A5F` + 0.5pt 골드 헤어라인 보더, 커넥터는 1pt 가는 라인(화살표는 셰브론 화살촉 절제), 단계 번호는 등폭 작은 골드 텍스트, 강조는 골드 헤어라인 또는 골드 텍스트.
- **프로세스 플로우:** 좌→우 사각 노드 4~5단계 — 네이비 패널 + 0.5pt 골드 헤어라인, 노드 사이 1pt 가는 셰브론. 각 노드 좌상단 등폭 골드 단계 번호. 노드 헤딩 세리프 14pt, 본문 12pt. 현재 단계만 골드 헤어라인 두께 1pt로 강조.
- **타임라인(분기·연도):** 수평 축 0.75pt `#3A5A85`. 마일스톤은 0.12in 골드 윤곽 다이아몬드(현재 분기만 골드 솔리드). 연도·분기 라벨 축 아래 등폭 10pt, 사건 라벨 축 위 세리프 13pt.
- **비교(세그먼트 표):** 다열 재무 표 — 0.5pt 골드 헤어라인 격자, 헤더 행 11pt 대문자 + 하단 골드 룰, 수치 셀 등폭 우정렬. 우세 세그먼트 행만 골드 텍스트.
- **매트릭스 2×2:** 0.5pt 골드 헤어라인 십자축. 사분면 라벨 세리프 14pt. 데이터 포인트는 0.14in 골드 윤곽 원(핵심만 골드 솔리드). 축 라벨 바깥 11pt 보조 텍스트.
- **계층/퍼널:** 폭 비례 사각 적층 — 네이비 명도 단계 채움, 핵심 단만 골드 헤어라인. 레벨 라벨 우측 세리프 14pt.
- **KPI·스탯 카드:** 네이비 패널 + 0.5pt 골드 헤어라인, 좌상단 11pt 대문자 라벨, 거대 40pt Source Serif 4 600 오프화이트 수치, 그 아래 14pt 골드 델타(YoY %). 카드 3~4개 가로 균등, 카드 사이 골드 헤어라인 구분.
- **목차/섹션 디바이더/인용:** 목차는 등폭 `01`~`NN` 골드 번호 + 세리프 항목명 + 우측 0.5pt 골드 헤어라인 구분 + 페이지 번호. 디바이더는 네이비 전면 + 좌측 거대 90pt 세리프 골드 윤곽 섹션 번호 + 26pt 세리프 섹션명 + 0.5pt 골드 룰. 인용은 네이비 패널 + 좌측 0.5pt 골드 헤어라인 + 22pt 세리프 풀쿼트 + 등폭 출처.

## 전환 (PPT)
subtle — 골드 헤어라인과 표 행이 220ms ease-out으로 짧게 페이드 인하는 정도만. 슬라이드 본문은 즉시 컷. 글로우·슬라이드 모션 금지.

## 하지 말 것
- 골드를 큰 면·버튼 배경으로 쓰지 말 것 — 0.5pt 헤어라인·라벨·차트 핵심 계열에만(면 채움은 저렴해 보인다).
- 헤딩에 산세리프 쓰지 말 것 — 트랜지셔널 세리프가 정체성.
- 그라디언트·글로우·그림자·둥근 모서리·이모지 금지.
- 우하단 디스클레이머 풋라인 생략 금지 — IR 정체성.
- 차트 y축 자르지 말 것 — 재무 수치 왜곡. 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 출처 누락.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
딥 네이비 전면. 좌상단 마진 0.65in에 11pt 골드 대문자 라벨 `INVESTOR RELATIONS · FY2025`. 캔버스 세로 중앙(상단 40%)에 26pt → 38pt로 키운 세리프 600 타이틀 좌측 정렬. 그 아래 0.15in에 0.5pt 골드 헤어라인 폭 4in + 그 아래 17pt 부제. 우하단 0.75in 풋라인: 0.5pt 골드 헤어라인 + 디스클레이머 8pt(좌) + 페이지 `01`(우).

### 02 · 목차 (agenda)
상단 11pt 골드 라벨 + 26pt 세리프 헤딩 + 0.5pt 골드 헤어라인. 본문 영역 좌측 7열에 목차 — 등폭 골드 `01`~`05` 번호 + 세리프 16pt 항목명 + 우측 점선 리더 + 페이지 번호, 항목 사이 0.5pt 골드 헤어라인. 우측 5열 비움. 우하단 디스클레이머 풋라인.

### 03 · 재무 하이라이트 본문 (body)
상단 골드 라벨 + 26pt 세리프 헤딩 + 골드 헤어라인. 본문 영역 좌측 5열에 17pt 본문 3~5줄, 우측 7열에 KPI 카드 3개(네이비 패널 + 골드 헤어라인, 40pt 세리프 오프화이트 수치 + 14pt 골드 YoY 델타). 우하단 풋라인.

### 04 · 다년 추이 차트 (chart)
상단 골드 라벨 + 26pt 세리프 헤딩. 본문 영역에 다년 추이 라인 차트 — 1pt 폴리라인, 핵심 시리즈 골드 + 비교 시리즈 오프화이트, 0.1in 원 마커, y축 주요 눈금 2~3개 0.5pt 네이비. 시리즈명 라인 끝 직접 라벨링, 값 레이블 14pt tabular. 하단 좌측 9pt 출처·통화·기준일 각주. 우하단 디스클레이머 풋라인.

### 05 · 세그먼트 비교 표 (comparison)
상단 골드 라벨 + 26pt 세리프 헤딩 + 골드 헤어라인. 본문 영역 전체에 다열 재무 표 — 0.5pt 골드 헤어라인 격자, 헤더 행 11pt 대문자 + 하단 골드 룰, 세그먼트별 행에 등폭 우정렬 수치(매출·마진·YoY). 합계 행 위 0.5pt 골드 룰 + 굵게. 우세 세그먼트 행만 골드 텍스트. 우하단 풋라인.

### 06 · 분기·연도 타임라인 (timeline)
상단 골드 라벨 + 26pt 세리프 헤딩. 본문 영역 중앙에 수평 타임라인 — 0.75pt 베이스 축, 분기·연도 라벨 등폭 10pt 축 아래, 마일스톤 0.12in 골드 윤곽 다이아몬드(현재 분기만 골드 솔리드) + 사건 세리프 13pt 축 위. 우하단 디스클레이머 풋라인.

### 07 · 전망·디스클레이머 클로징 (closing)
딥 네이비 전면. 상단 골드 라벨 + 26pt 세리프 헤딩 "전망". 본문 영역 좌측 6열에 17pt 가이던스 본문, 우측 6열에 네이비 패널 + 골드 헤어라인 박스에 핵심 전망 수치. 캔버스 하단 1/3에 작은 8pt 보조 텍스트 디스클레이머 단락(forward-looking statement 고지). 우하단 풋라인.
