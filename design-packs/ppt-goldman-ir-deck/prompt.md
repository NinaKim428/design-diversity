# 골드만 IR 덱 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 골드만 IR 덱 — 딥 네이비 전면 페이지에 메탈릭 골드 0.5pt 헤어라인이 헤더·섹션·표를 구획하고, 보수적인 트랜지셔널 세리프 헤딩과 등폭 숫자의 재무 표가 권위를 만드는 투자은행 IR·earnings 덱. 우하단에 디스클레이머 풋라인 의무.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드 전면이 딥 네이비 `#0A1A33`, 오프화이트 텍스트 — 보수적 금융 권위, (2) 메탈릭 골드는 0.5pt 헤어라인·라벨에만 — 헤더 밑줄·섹션 구획·표 룰로 가늘게 흐르고 절대 면으로 쓰지 않는다, (3) 헤딩은 트랜지셔널 세리프, 재무 표는 등폭 우정렬. 우하단에 항상 디스클레이머 + 페이지네이션 풋라인.

## 색
- 배경 딥 네이비 `#0A1A33` (전면)
- 패널 네이비 `#1F3A5F`
- 강조 메탈릭 골드 `#C8A24B` — 0.5pt 헤어라인·라벨·차트 핵심 계열에만. 면·버튼 배경으로 절대 쓰지 않는다.
- 텍스트 오프화이트 `#E8E5DE`
- 보조 텍스트 `#9AA6BC`
- 강조색은 골드 1개뿐. 차트 시리즈는 골드 + 오프화이트 + 네이비 명도 단계. 그라디언트·글로우 금지.
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B`·`$M` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다). 재무 표는 통화 단위를 헤더에 명기.

## 타이포그래피
- 폰트: 헤딩 `Source Serif 4`(트랜지셔널 세리프, 대체 `Georgia, "Times New Roman", serif`). 본문·숫자 `Inter`(대체 `Arial, sans-serif`). 한글 헤딩은 `Pretendard`(굵게), 본문도 `Pretendard`.
- 슬라이드 헤딩: 26pt / Source Serif 4 600 / 자간 0 / 오프화이트
- 섹션 라벨(골드): 11pt / Inter 500 / 자간 +8% / 대문자 / 색 골드
- 본문: 17pt / Inter 400 / 행간 1.4 / 슬라이드당 6줄 이하
- 재무 표 헤더: 11pt / Inter 600 / 대문자 / 자간 +6%
- 재무 표 숫자: 14pt / Inter 400 / tabular numerals / 우정렬
- KPI 대형 수치: 40pt / Source Serif 4 600 / tabular 느낌
- 디스클레이머 풋라인: 8pt / Inter 400 / 색 보조 텍스트

## 레이아웃 / 그리드
- **엄격 12열 그리드(balanced) + 고정 외곽 여백.** 1280×720 기준 좌·우·상 외곽 여백 각 64px 고정, 하단 풋라인 baseline 64px 고정 — 모든 슬라이드 동일, 드리프트 금지. 12열 거터 0.2in.
- 슬라이드 상단: 26pt 세리프 헤딩(baseline 덱 전체 동일 y 고정) + 그 아래 0.5pt 골드 헤어라인 풀폭(헤더 구획선) — 헤딩은 일관 크기, 강조는 골드 색으로(문장 중간 단어 비대 금지).
- 좌상단 또는 헤더 위에 11pt 골드 섹션 라벨(대문자, 자간 +0.14em).
- 본문 영역은 12열 그리드 — 재무 표·차트가 스냅, 떠다니는(off-grid) 요소 금지. 표는 등폭 숫자 우정렬, 수직 리듬 24/32/48px 스텝.
- **구성 균형:** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다. 본문 영역의 빈 다크 네이비 공간을 한 구석에 고이게 두지 않고 모듈로 고르게 채운다(밀도 원칙 참조).
- 풋라인: 콘텐츠 폭 전체 0.5pt 골드 헤어라인 위에 디스클레이머(좌하단, 8pt) + 페이지 번호(우하단, 8pt) — 풋라인 baseline에 정렬, 모든 슬라이드 의무·덱 전체 동일 처리.
- **밀도 원칙:** 실제 IR earnings 페이지는 정보 밀도가 높다 — 다년 차트 + 재무 표 + KPI 스트립 + 주석이 한 페이지에 공존한다. 헤더 하단~풋라인 사이 본문 영역의 빈 다크 여백을 최소화하고 캔버스 88% 이상을 **모듈 3개 이상**으로 채운다. 거대한 네이비 여백에 작은 라인차트 하나만 띄우는 것 금지.
- **모듈 좌표 컨벤션:** 7:5 분할(좌 7열 차트/표 + 우 5열 KPI/해설) 또는 헤더 하단 풀폭 다년 차트 + 그 아래 재무 표 + 하단 KPI 스트립의 3단. 모듈 사이 거터 0.2in.
- **주석 콜아웃:** 네이비 패널 `#1F3A5F` + 0.5pt 골드 헤어라인 윤곽, 안에 13pt 인사이트 1~2줄 + 좌상단 등폭 골드 라벨. 박스 높이는 내용 높이 + 일관 패딩(상하 좌우 0.16in)으로 — 하단 절반이 비지 않는다. 차트 변곡점·표 핵심 행 옆에 1개 배치해 재무 수치의 해석을 명시.
- **레퍼런스 미세 디테일:** 골드 헤어라인은 덱 전체 0.5~1px 일관. 재무 표는 헤더행 11pt 대문자 + 하단 골드 룰로 구분, 행 룰 1px 네이비 헤어라인, 합계행 위 골드 룰 + 굵게, 강조 셀/행은 1개만. 수치는 tabular figures, 표 안 소수점 정렬·소수 자릿수·통화 단위 일관. 텍스트 좌측 엣지 동일 x, tabular 수치는 우정렬.

## 형태 / 질감
- 모서리 반경 0px. 보더는 0.5pt 골드 헤어라인 또는 1px 네이비 룰. 그림자·그라디언트·글로우 전면 금지.
- 패널은 네이비 `#1F3A5F` 채움 — 골드는 절대 면으로 쓰지 않는다.
- 골드 헤어라인이 구획 장치(헤더 밑줄·섹션 분리·표 룰). 아이콘 거의 안 씀 — 쓴다면 1pt 가는 라인 골드 단색.

## 차트·데이터 시각화 (재무 익스히빗 차트 — 골드 + 네이비 명도)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). IR earnings 차트 — 보수적, 등폭 숫자, 출처 각주.
- **데이터 색:** 차트 시리즈는 골드 `#C8A24B` + 오프화이트 `#E8E5DE` + 네이비 명도 단계 `#1F3A5F`/`#3A5A85`만. 강조 1계열만 골드. 무지개 채색 금지.
- **다년 추이 라인:** 1pt 폴리라인, 핵심 시리즈만 골드, 비교 시리즈는 오프화이트. 마커는 0.1in 작은 원. 면적 채움 없거나 아주 옅은 골드 8% 채움.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0에서 정확히(잘린 y축 절대 금지 — 재무 왜곡).
- **데이터 잉크 최소화:** 격자선은 y축 주요 눈금 2~3개 0.5pt `#1F3A5F`만. 차트 테두리 박스 제거. 축선 0.75pt `#3A5A85`.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 14pt Inter 400 tabular 우정렬, 단위·자릿수·통화 일관(예 `$M`·`%`). 범례 박스 금지 — 시리즈명 라인·막대 끝에 직접 라벨링.
- **재무 표:** 등폭 숫자 우정렬, 헤더 행만 11pt 대문자 + 하단 0.5pt 골드 룰. 행 사이 1px 네이비 룰. 합계 행은 위 0.5pt 골드 룰 + 굵게.
- **출처:** 차트 하단 좌측 9pt Inter `#9AA6BC` 출처·기준일·통화 각주 의무.
- **타입 매칭:** 추세=다년 라인, 비교=세로 막대, 비중=100% 누적 막대 또는 도넛 1개. 파이 다중·3D·도넛 다중 금지.

## 다이어그램·컴포넌트 (IR 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 네이비 패널 `#1F3A5F` + 0.5pt 골드 헤어라인 보더, 커넥터는 1pt 가는 라인(화살표는 셰브론 화살촉 절제), 단계 번호는 등폭 작은 골드 텍스트, 강조는 골드 헤어라인 또는 골드 텍스트.
- **프로세스 플로우:** 좌→우 사각 노드 4~5단계 — 네이비 패널 + 0.5pt 골드 헤어라인, 노드 사이 1pt 가는 셰브론. 각 노드 좌상단 등폭 골드 단계 번호. 노드 헤딩 세리프 14pt, 본문 12pt. 현재 단계만 골드 헤어라인 두께 1pt로 강조.
- **타임라인(분기·연도):** 수평 축 0.75pt `#3A5A85`. 마일스톤은 0.12in 골드 윤곽 다이아몬드(현재 분기만 골드 솔리드). 연도·분기 라벨 축 아래 등폭 10pt, 사건 라벨 축 위 세리프 13pt.
- **비교(세그먼트 표):** 다열 재무 표 — 0.5pt 골드 헤어라인 격자, 헤더 행 11pt 대문자 + 하단 골드 룰, 수치 셀 등폭 우정렬. 우세 세그먼트 행만 골드 텍스트.
- **매트릭스 2×2:** 0.5pt 골드 헤어라인 십자축. 사분면 라벨 세리프 14pt. 데이터 포인트는 0.14in 골드 윤곽 원(핵심만 골드 솔리드). 축 라벨 바깥 11pt 보조 텍스트.
- **계층/퍼널:** 폭 비례 사각 적층 — 네이비 명도 단계 채움, 핵심 단만 골드 헤어라인. 레벨 라벨 우측 세리프 14pt.
- **KPI·스탯 카드:** 네이비 패널 + 0.5pt 골드 헤어라인, 좌상단 11pt 대문자 라벨, 거대 40pt Source Serif 4 600 오프화이트 수치, 그 아래 14pt 골드 델타(YoY %). 카드 3~4개 가로 균등, 카드 사이 골드 헤어라인 구분.
- **목차/섹션 디바이더/인용:** 목차는 등폭 `01`~`NN` 골드 번호 + 세리프 항목명 + 우측 0.5pt 골드 헤어라인 구분 + 페이지 번호. 디바이더는 네이비 전면 + 좌측 거대 90pt 세리프 골드 윤곽 섹션 번호 + 26pt 세리프 섹션명 + 0.5pt 골드 룰. 인용은 네이비 패널 + 좌측 0.5pt 골드 헤어라인 + 22pt 세리프 풀쿼트 + 등폭 출처.

## 전환 (PPT)
subtle — 골드 헤어라인과 표 행이 220ms ease-out으로 짧게 페이드 인하는 정도만. 슬라이드 본문은 즉시 컷. 글로우·슬라이드 모션 금지.

## 하지 말 것
- 골드를 큰 면·버튼 배경으로 쓰지 말 것 — 0.5pt 헤어라인·라벨·차트 핵심 계열에만(면 채움은 저렴해 보인다).
- 헤딩에 산세리프 쓰지 말 것 — 트랜지셔널 세리프가 정체성.
- 그라디언트·글로우·그림자·둥근 모서리·이모지 금지.
- 우하단 디스클레이머 풋라인 생략 금지 — IR 정체성.
- 차트 y축 자르지 말 것 — 재무 수치 왜곡. 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 출처 누락.
- **거대한 네이비 여백에 차트/표 하나만 띄우기 금지.** 실제 IR 페이지는 빽빽하다 — 모든 본문/차트/표 슬라이드는 모듈 3개 이상(차트 + 표 + KPI 스트립 또는 주석) + 출처 각주 + 디스클레이머 풋라인.
- **캔버스 한 구석에 죽은 네이비 공백을 고이게 두지 말 것 / 빈 플레이스홀더 블록 금지 / 헤딩 문장 중간 단어 비대 금지 / 외곽 여백·풋라인·헤딩 baseline 위치 드리프트 금지.** 외곽 여백 64px·풋라인 baseline 64px·헤딩 baseline을 슬라이드 전체에서 고정한다.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
딥 네이비 전면. 좌상단 마진 0.65in에 11pt 골드 대문자 라벨 `INVESTOR RELATIONS · FY2025`. 캔버스 세로 중앙(상단 40%)에 26pt → 38pt로 키운 세리프 600 타이틀 좌측 정렬. 그 아래 0.15in에 0.5pt 골드 헤어라인 폭 4in + 그 아래 17pt 부제. 타이틀 우측 5열에 네이비 패널 + 0.5pt 골드 헤어라인 메타 박스 — 등폭 라벨/값 3행(`TICKER` · `REPORTING PERIOD` · `EARNINGS CALL DATE`). 우하단 0.75in 풋라인: 0.5pt 골드 헤어라인 + 디스클레이머 8pt(좌) + 페이지 `01`(우). 표지는 절제 허용하되 메타 박스로 우측을 채운다.

### 02 · 목차 (agenda)
상단 11pt 골드 라벨 + 26pt 세리프 헤딩 + 0.5pt 골드 헤어라인. 본문 영역 좌측 7열에 목차 — 등폭 골드 `01`~`05` 번호 + 세리프 16pt 항목명 + 그 아래 13pt 보조 텍스트 한 줄 설명 + 우측 점선 리더 + 페이지 번호, 항목 사이 0.5pt 골드 헤어라인 + 섹션 진행 인디케이터(현재 섹션 좌측 1pt 골드 룰). 우측 5열에 네이비 패널 + 골드 헤어라인 — 이번 분기 헤드라인 수치 3개를 미니 KPI 행으로(40pt 세리프 + 14pt 골드 YoY). 우하단 디스클레이머 풋라인.

### 03 · 재무 하이라이트 본문 (body)
상단 골드 라벨 + 26pt 세리프 헤딩 + 골드 헤어라인 + 그 아래 13pt 보조 텍스트 리드 1줄. 본문 영역 좌측 5열에 17pt 본문 3~4줄(핵심 구절 골드) + 그 아래 재무 하이라이트 미니 표(3~4행 헤어라인 격자). 우측 7열을 상하 2단 — 상단에 KPI 카드 4개 그리드(네이비 패널 + 골드 헤어라인, 11pt 대문자 라벨 + 40pt 세리프 오프화이트 수치 + 14pt 골드 YoY 델타 + 가는 미니 스파크라인), 하단에 보조 막대 차트 1개. 차트 옆에 네이비 패널 주석 콜아웃 1개. 우하단 풋라인.

### 04 · 다년 추이 차트 (chart)
상단 골드 라벨 + 26pt 세리프 헤딩. 본문 영역 좌측 7열에 메인 다년 추이 라인 차트 — 1pt 폴리라인, 핵심 시리즈 골드 + 비교 시리즈 오프화이트, 0.1in 원 마커, y축 주요 눈금 2~3개 0.5pt 네이비, 각 데이터 포인트 14pt tabular 값 레이블. 추이선 변곡점에 골드 헤어라인 콜아웃 박스 2~3개(가는 리더선 + 13pt 설명). 우측 5열을 상하 2단 — 상단에 연도별 원수치 재무 표(0.5pt 골드 헤어라인 격자, 등폭 우정렬), 하단에 KPI 요약 스트립(`CAGR` · `5Y 누계` · `YoY` 3개 셀, 11pt 대문자 라벨 + 40pt 세리프). 시리즈명 라인 끝 직접 라벨링, 통화 단위 명기. 하단 좌측 9pt 출처·통화·기준일 각주. 우하단 디스클레이머 풋라인.

### 05 · 세그먼트 비교 표 (comparison)
상단 골드 라벨 + 26pt 세리프 헤딩 + 골드 헤어라인. 본문 영역 좌측 8열에 본격 다열 재무 표 — 0.5pt 골드 헤어라인 격자, 헤더 행 11pt 대문자 + 하단 골드 룰, 세그먼트별 행 5~6개에 등폭 우정렬 수치(매출 · 영업이익 · 마진 · YoY · 비중 5열). 합계 행 위 0.5pt 골드 룰 + 굵게. 우세 세그먼트 행만 골드 텍스트. 우측 4열을 상하 2단 — 상단에 세그먼트별 비중 100% 누적 막대 또는 도넛 1개, 하단에 네이비 패널 평결 콜아웃 박스(13pt 핵심 해석 + 골드 라벨). 우하단 풋라인.

### 06 · 분기·연도 타임라인 (timeline)
상단 골드 라벨 + 26pt 세리프 헤딩. 본문 영역 상단에 멀티트랙 수평 타임라인 — 0.75pt 베이스 축, 분기·연도 날짜축 라벨 등폭 10pt 축 아래, 페이즈 밴드(`FY2024` · `FY2025` · `FY2026E` 구간 옅은 네이비 띠), 마일스톤 0.12in 골드 윤곽 다이아몬드(현재 분기만 골드 솔리드) + 사건 세리프 13pt 축 위 + 마일스톤 설명 11pt. 'today' 마커를 1pt 골드 수직 점선으로. 타임라인 아래에 분기별 핵심 수치 미니 표(3~4행) + 골드 헤어라인 콜아웃 1개. 우하단 디스클레이머 풋라인.

### 07 · 전망·디스클레이머 클로징 (closing)
딥 네이비 전면. 상단 골드 라벨 + 26pt 세리프 헤딩 "전망". 본문 영역 좌측 6열에 17pt 가이던스 본문 3~4줄 + 그 아래 다음 분기 가이던스 미니 표(2~3행). 우측 6열에 네이비 패널 + 골드 헤어라인 박스에 핵심 전망 수치 KPI 3개(40pt 세리프 + 14pt 골드 레인지). 캔버스 하단 1/4에 작은 8pt 보조 텍스트 디스클레이머 단락(forward-looking statement 고지). 우하단 풋라인.
