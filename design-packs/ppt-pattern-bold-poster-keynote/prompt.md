# Pattern 볼드 포스터 키노트 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. Pattern 볼드 포스터 키노트 — 슬라이드 전면을 채도 높은 단색 한 가지로 도배하고, 그 위에 거대한 굵은 산세리프 헤드라인을 포스터처럼 앉히는 정적·미니멀 키노트. 컴포넌트는 최소, 색이 페이지를 정의하고 타이포가 이미지를 대신한다.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드마다 화면 전체가 채도 높은 단색 한 가지 — 일렉트릭 블루 또는 버밀리언, 슬라이드 넘기면 색이 교대된다, (2) 거대 굵은 산세리프 헤드라인이 90~140px로 포스터처럼 좌상 또는 중앙에 앉는다, (3) 컴포넌트는 작은 라벨·페이지 번호 정도뿐 — 거대 타이포 주변에 넉넉한 여백. 정적인 포스터 시리즈.

## 색
- 페이지 색 A 일렉트릭 블루 `#1F3DFF`
- 페이지 색 B 버밀리언 `#FF4D2E`
- 잉크 `#0E0E0E` (블루 페이지 위 텍스트·도형)
- 반전 타입 `#FFFFFF` (버밀리언/블루 페이지 위 흰 헤드라인)
- 한 슬라이드는 단색 면 1가지만 — A 또는 B, 슬라이드마다 교대. 그라디언트·사진 금지.
- 텍스트는 흰색 또는 잉크 — 단색 면 위 대비. 강조색이라는 개념 자체가 페이지 색.
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 헤드라인 `Anton`(본질적 heavy display, 대체 `'Arial Black', Impact, sans-serif`). 라벨 `Archivo` 600(대체 `Arial`). 한글 헤드라인은 `Pretendard` 900(굵게).
- 헤드라인: 90~140px(16:9에서 약 68~105pt) / Anton 400 / 자간 -1% / 행간 0.95
- 부제(있다면): 24pt / Archivo 600 / 자간 +2%
- 라벨·페이지 번호: 13pt / Archivo 600 / 자간 +8% / 대문자
- 본문(스테이트먼트 슬라이드): 28pt / Archivo 600 / 행간 1.3 / 슬라이드당 3줄 이하
- KPI 거대 숫자: 200~280px / Anton 400 / tabular numerals

## 레이아웃 / 그리드
- **풀블리드 단색 면(airy).** 마진 없이 색이 엣지투엣지. 콘텐츠 안전 여백 0.7in.
- 거대 헤드라인을 좌상 정렬 또는 중앙 — 슬라이드마다 위치를 살짝 바꿔 리듬을 만든다.
- 라벨·페이지 번호는 모서리(좌상 또는 우하)에 작게.
- **두 종류의 슬라이드를 구분한다.** (1) **포스터 슬라이드**(표지·간지·스테이트먼트·클로징) — 거대 타이포 + 넓은 여백, 절제 유지. (2) **데이터 슬라이드**(본문·KPI·차트·비교·다이어그램) — 단색 면 위에 거대 헤드라인 + **흰 1px 윤곽으로 구획된 데이터 모듈 3개 이상**(거대 막대 차트 / 흰 윤곽 데이터 표 / 거대 숫자 KPI 행 / 흰 윤곽 콜아웃). "포스터지만 빈약하지 않다" — 데이터 슬라이드는 단색 면을 흰 윤곽 모듈로 채운다.
- **데이터 모듈 컨벤션:** 단색 면 위 흰색 0.75~1px 윤곽 직사각형(채움 없음, 반경 0px). 모듈 안에 거대 숫자/차트/표를 흰색으로. 모듈을 2×2 또는 1×3 그리드로 면 위에 배치 — 모듈 사이 간격 0.5in, 단색 면이 거터로 보이게.
- **흰 윤곽 콜아웃:** 흰 1px 윤곽 사각형 + 안에 28pt Archivo 600 인사이트 1줄. 차트/표 옆에 1개 배치해 "그래서 무엇을"을 명시.

## 형태 / 질감
- 모서리 반경 0px. 보더·그림자·아이콘 거의 없음. 완전 평면.
- 색이 페이지를 통째로 정의 — 도형을 거의 쓰지 않는다.
- 차트·도형이 필요하면 단색 면 위 화이트/잉크 단순 도형(채움 없는 윤곽 또는 흰 솔리드)만.

## 차트·데이터 시각화 (포스터 차트 — 단색 면 위 화이트/잉크 도형)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 포스터처럼 거대·단순하되, 데이터 슬라이드에서는 차트가 빈 면을 채우는 모듈이다.
- **데이터 색:** 단색 페이지 면 위에 흰색 솔리드 또는 잉크 윤곽만. 두 톤(흰 솔리드 / 흰 윤곽)으로 계열 구별. 추가 색 금지.
- **막대 형태:** 막대는 거대하고 적게(3~6개), 막대 폭 : 간격 = 2 : 1. 모서리 0px. 베이스라인 0(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선 전면 제거. 축선도 최소(흰 0.75pt 한 줄 또는 없음). 차트 테두리 박스 없음.
- **값 레이블:** 막대 끝에 거대하게 직접 표기 — 28~40pt Archivo 600 흰색. 카테고리명 14pt. 범례 박스 금지.
- **변곡점 콜아웃:** 차트 위 핵심 막대/꼭짓점에 흰 1px 윤곽 콜아웃 박스 2~3개(28pt 인사이트 + 가는 흰 리더선).
- **보조 데이터 표:** 단색 면 위 흰 1px 윤곽 표 — 3~4행, 행 사이 흰 0.75px 룰, 셀값 흰 24pt. 차트 옆에 두어 원수치를 받친다.
- **KPI 스트립:** 차트 슬라이드 하단에 거대 숫자 KPI 3개를 흰 윤곽 모듈 행으로(80~120pt Anton 숫자 + 24pt 라벨).
- **출처:** 슬라이드 모서리에 13pt 라벨로 출처 한 줄 + 페이지 번호.
- **타입 매칭:** 비교=거대 세로 막대 3~6개, 비중=거대 도넛 1개(조각 2~3개, 흰/윤곽), KPI=거대 숫자. 추세는 굵은 흰 폴리라인 1개. 파이 다중·3D·격자선 금지.

## 다이어그램·컴포넌트 (포스터 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 요소는 단색 면 위 흰색 솔리드 또는 잉크 윤곽, 각진(반경 0px), 거대·단순, 텍스트 위계로 흐름을 표현(커넥터 최소화), 라벨은 13pt 대문자.
- **프로세스 플로우:** 거대 단계 번호(80~120pt Anton 흰색/잉크) 3~4개를 가로 나열, 각 아래 14pt 라벨. 노드 박스 없음 — 거대 번호와 넓은 간격이 흐름. 커넥터 없거나 굵은 흰 화살표 1개.
- **타임라인:** 굵은 흰 수평 라인 1개(4pt). 마일스톤은 0.2in 흰 솔리드 원, 큰 24pt 날짜 라벨. 최소한의 마커.
- **비교(2열):** 슬라이드를 좌우 두 색면으로 분할(좌 블루 / 우 버밀리언) — 각 면에 거대 헤드라인 + 거대 숫자. 가운데 'VS' 또는 분할선 없음(색 경계가 구분).
- **매트릭스 2×2:** 단색 면 위 흰 0.75pt 십자축. 사분면에 거대 라벨 28pt. 데이터 포인트는 0.2in 흰 솔리드 원. 최소 장식.
- **계층/퍼널:** 거대 흰 사각 적층 3~4단, 폭 비례. 각 단에 거대 28pt 라벨. 단색 면 위 흰 솔리드/윤곽 교대.
- **KPI·스탯 카드:** 카드 박스 없음 — 단색 면 위에 거대 200~280px Anton 숫자 한 점 + 그 아래 24pt 라벨. 슬라이드당 KPI 1개.
- **목차/섹션 디바이더/인용:** 목차는 거대 `01`~`NN` Anton 번호 세로 나열 + 24pt 항목명. 디바이더는 단색 면 전환 + 중앙 거대 헤드라인. 인용은 단색 면 위 거대 60~80pt Anton 풀쿼트(흰색) + 13pt 출처 라벨.

## 전환 (PPT)
없음(즉시 컷). 정적 포스터 시리즈 — 단색 면과 거대 타이포의 정지된 강렬함으로 승부. 빌드·페이드 애니메이션 금지. 슬라이드 넘김 = 색 교대.

## 하지 말 것
- 한 슬라이드에 2색 이상 면 금지(좌우 분할 비교 슬라이드 예외) — 페이지 = 단색 1가지가 정체성.
- 그라디언트·사진·이모지·클립아트 금지.
- 헤드라인을 작게 쓰지 말 것 — 90~140px 거대해야 한다.
- 흐린 파스텔·무채색 면으로 회귀 금지 — 채도 높은 원색만.
- 차트 회귀: 3D, 격자선, 범례 박스, 작은 차트, 추가 색.
- **데이터 슬라이드(본문·KPI·차트·비교)를 거대 숫자/차트 하나만 두고 비우기 금지.** 포스터 미감은 표지·간지·클로징에서 유지하되, 데이터 슬라이드는 흰 윤곽 모듈 3개 이상으로 단색 면을 채운다 — "포스터지만 빈약하지 않다". 모든 데이터 슬라이드에 출처 라벨 + 페이지 번호.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
일렉트릭 블루 `#1F3DFF` 전면. 좌상단 0.7in 안전 여백에 13pt 흰색 대문자 라벨. 캔버스 중앙~좌하단에 거대 헤드라인(약 105pt Anton, 흰색, 좌상 정렬, 2~3줄, 행간 0.95). 우하단 모서리에 흰 1px 윤곽 메타 스트립(`PRESENTED BY` · `DATE` 2행, 13pt) + 페이지 라벨. 표지는 포스터 — 색면 + 거대 타이포 + 넓은 여백, 절제 유지.

### 02 · 섹션 간지 (단색 전환) (section-divider)
직전 슬라이드와 다른 색면으로 전환(블루→버밀리언). 캔버스 중앙에 거대 헤드라인(약 120pt Anton, 흰색, 중앙 정렬) — 섹션명 한 단어. 그 위 13pt 대문자 섹션 번호(`SECTION 02`). 헤드라인 아래에 이 섹션 항목 3개를 거대 Anton 번호 + 24pt 라벨 인덱스로. 간지는 포스터 — 절제 유지하되 항목 인덱스로 하단을 채운다.

### 03 · 목차 (agenda)
단색 면 전면. 좌측에 거대 `01`~`05` Anton 번호(약 70pt 흰색) 세로 나열, 각 옆에 24pt Archivo 600 항목명 + 그 아래 14pt 한 줄 설명 + 우측 페이지 번호. 항목 사이 흰 0.75px 룰 + 현재 섹션 진행 마커(흰 솔리드 사각). 상단 13pt 대문자 라벨 `CONTENTS`. 우측 절반에 흰 1px 윤곽 모듈 — 덱 핵심 메시지 한 줄(28pt) + takeaway 3개.

### 04 · 스테이트먼트 + 데이터 본문 (body)
단색 면 전면. 캔버스 좌상~중앙에 28pt Archivo 600 스테이트먼트 본문 2~3줄, 핵심 단어 하나는 거대 헤드라인 크기(약 90pt Anton)로 강조. 본문 영역 하단을 흰 1px 윤곽 데이터 모듈 3개 1×3 그리드 — 각 모듈에 거대 숫자(80~120pt Anton) + 24pt 라벨 + 14pt 맥락 1줄. 그 옆 흰 윤곽 콜아웃 1개(28pt 인사이트). 모서리에 13pt 라벨 + 페이지 번호. 포스터 톤이되 모듈 3개로 채운다.

### 05 · 거대 숫자 KPI (kpi)
단색 면 전면(블루 또는 버밀리언). 캔버스 상단에 거대 KPI 영웅 숫자 한 점(약 200px Anton, 흰색, tabular) + 24pt 라벨. 그 아래에 흰 1px 윤곽 KPI 카드 4개 2×2 그리드 — 각 카드: 24pt 라벨 + 80~100pt Anton 수치 + 24pt ▲▼ 델타 + 가는 흰 미니 스파크라인. 모서리에 13pt 출처 라벨 + 페이지 번호. 거대 숫자 1개만 두지 말 것 — 카드 그리드로 채운다.

### 06 · 데이터 비교 / 차트 (comparison)
슬라이드를 좌우 두 색면으로 분할(좌 블루 / 우 버밀리언) — 각 면에 거대 헤드라인 + 거대 숫자 + 흰 1px 윤곽 데이터 표(3~4행, 항목별 수치). 또는 단색 면 1색 + 거대 세로 막대 차트 5~6개(흰 솔리드, 막대 폭:간격 2:1, 막대 끝 28pt 값) + 변곡점 흰 윤곽 콜아웃 2개 + 하단 KPI 스트립 3개. 색 경계가 구분, 모서리에 13pt 출처 라벨 + 페이지 번호.

### 07 · 클로징 (closing)
단색 면 전환. 캔버스 중앙에 거대 클로징 헤드라인(약 110pt Anton, 흰색). 그 아래 24pt 부제 1줄 + 다음 단계 3개(거대 Anton 번호 + 24pt 라벨). 우하단 모서리에 13pt 컨택트 라벨 + 페이지 번호. 정지된 포스터 — 빌드 애니메이션 없음.
