# 베인 리절츠 덱 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 베인 리절츠 덱 — 슬라이드 중앙 상단에 거대한 결과 메트릭 한 점(예 `+34%`)이 지배하고, 그 아래 작은 캡션이 맥락을 다는 'results-first' 컨설팅 덱. 베인 레드 단 한 점, 중앙 정렬 단일 축, 넉넉한 흰 여백.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드마다 거대 숫자 한 점이 시선을 독점한다 — `+34%`·`2.7×`·`$1.2B` 같은 결과 메트릭이 160~200px로, 베인 레드, (2) 모든 것이 중앙 세로축 기준 정렬 — 비교조차 중앙 좌우 대칭, (3) 무채색 + 레드 단 한 점. 성과를 먼저 보여주고 설명을 나중에 다는 results-first 덱.

## 색
- 배경 `#FFFFFF` (순백)
- 패널(before 상태) `#F4F5F6` (아주 옅은 그레이)
- 본문 잉크/헤딩 `#111827`
- 캡션 그레이 `#9CA3AF`
- 강조 베인 레드 `#CC0000` — 거대 결과 숫자·델타 화살표에만. 면(배경)·텍스트 본문에 쓰지 않는다.
- 강조색은 레드 1개뿐. 차트 색은 무채 명도 + 레드 한 점. 그라디언트 금지.

## 타이포그래피
- 폰트: 전부 `Inter`(대체 `Helvetica Neue, Arial, sans-serif`). 한글은 `Pretendard`.
- 거대 결과 메트릭: 160~200px(16:9에서 약 120~150pt) / Inter 800 / 자간 -2% / 색 베인 레드 / tabular numerals
- 메트릭 캡션: 16pt / Inter 400 / 색 캡션 그레이 / 중앙 정렬
- 슬라이드 제목(메트릭 없는 본문 슬라이드): 32pt / Inter 700 / 중앙 정렬
- 본문: 20pt / Inter 400 / 행간 1.45 / 슬라이드당 5줄 이하
- 비교 칼럼 헤더: 14pt / Inter 600 / 자간 +4% / 대문자
- 보조 수치: 28pt / Inter 700 / tabular

## 레이아웃 / 그리드
- **중앙 정렬 단일 축(balanced).** 좌우 마진 각 0.8in, 상하 0.6in. 모든 핵심 요소가 캔버스 세로 중심선 기준 정렬.
- 결과 메트릭 슬라이드: 거대 숫자를 중앙 상단(상단 28~40% 지점)에 한 점, 그 아래 16pt 캡션, 더 아래에 보조 차트·텍스트.
- 비교 슬라이드: before→after 두 칼럼을 중심선 좌우 대칭. 칼럼 폭 동일, 칼럼 사이 0.6in 간격.
- 흰 여백은 넉넉하되 비우기만 하지 않는다 — 메트릭 + 캡션 + 보조 요소가 한 슬라이드에 균형 공존(balanced).

## 형태 / 질감
- 보더 없음, 모서리 반경 0px, 그림자 전면 금지. 완전 평면.
- before 상태 패널만 옅은 그레이 `#F4F5F6` 채움(after는 흰 배경 그대로 — 굵기·색 대비로 차이 표현).
- 아이콘 거의 안 씀 — 델타 표시는 ▲▼ 삼각형 또는 화살표(레드)만. 카드 테두리 없음.

## 차트·데이터 시각화 (results-first 차트 — 무채 + 레드 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트는 거대 메트릭의 근거를 받친다.
- **데이터 색:** 막대·선 기본은 무채색 `#D1D5DB`(연) / `#6B7280`(진). 강조할 1개 막대·결과 시점 1개만 베인 레드 솔리드. 무지개 채색 금지.
- **추이 차트:** 1.5pt 폴리라인, 면적 채움 없음. 시작점 무채색, 결과(최종) 시점만 레드 원 마커 0.16in + 그 옆 거대 델타 라벨. 추세선 외 장식 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0에서 정확히(잘린 y축 절대 금지).
- **데이터 잉크 최소화:** 격자선 제거. 차트 테두리 박스·배경 채움 제거. x축선 0.75pt `#9CA3AF`, y축선 생략 가능.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 14pt Inter 600 tabular. 결과 값만 28pt 레드로 크게. 범례 박스 금지 — 직접 라벨링.
- **출처:** 차트 하단 좌측 10pt Inter `#9CA3AF` 출처·단위 각주 의무.
- **타입 매칭:** 비교=세로 막대, 추세=라인, 비중=도넛 1개(조각 3개 이하, 중앙에 핵심 수치). before/after는 두 막대 좌우 대칭. 파이 5조각 이상·3D·도넛 다중 금지.

## 다이어그램·컴포넌트 (results-first 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 요소는 보더 없는 평면, 중앙축 기준 대칭 배치, 커넥터는 1.5pt 가는 화살표 또는 ▲ 델타 삼각형(레드), 거대 수치 + 작은 캡션의 위계가 프로세스·KPI·비교 전반에 동일.
- **프로세스 플로우:** 좌→우 3~5단계, 각 단계는 거대 단계 번호(48pt Inter 800 무채색) + 그 아래 14pt 캡션. 단계 사이 1.5pt 가는 화살표 `#9CA3AF`. 노드 박스 없음 — 번호 크기와 화살표가 흐름. 핵심 단계 번호만 레드.
- **타임라인:** 수평 축 0.75pt `#9CA3AF`. 마일스톤은 0.14in 무채색 원, 결과 달성 시점만 레드 솔리드 원 + 그 위 거대 메트릭. 날짜 라벨 축 아래 12pt.
- **비교(before/after):** 중심선 좌우 두 칼럼. before 칼럼은 옅은 그레이 패널 + 무채색 수치, after 칼럼은 흰 배경 + 레드 결과 수치. 칼럼 헤더 14pt 600 대문자. 중앙에 ▲ 델타 삼각형 + 델타 값.
- **매트릭스 2×2:** 0.75pt 무채색 십자축. 데이터 포인트는 동일 크기 점(무채색), 목표 사분면 점만 레드. 사분면 라벨 14pt 600.
- **계층/퍼널:** 폭 비례 사각 적층(중앙 정렬 대칭). 무채색 명도 단계, 결과 단(최하 또는 최상)만 레드. 각 단 우측 거대 수치.
- **KPI·스탯 카드:** 보더 없는 카드, 거대 100~120pt Inter 800 레드 수치(또는 무채), 그 아래 16pt 캡션 그레이, 더 아래 14pt ▲▼ 델타. 카드 2~3개 중앙 정렬 가로 균등.
- **목차/섹션 디바이더/인용:** 목차는 `01`~`NN` 무채색 번호 + 20pt 항목명, 중앙 정렬. 디바이더는 흰 배경 중앙에 거대 레드 섹션 번호 + 32pt 섹션명. 인용은 중앙 정렬 28pt 700 풀쿼트 + 그 아래 14pt 출처.

## 전환 (PPT)
없음(즉시 컷). results-first 덱은 정적 — 거대 메트릭이 등장 효과 없이 즉시 시선을 잡는다. 빌드 애니메이션 금지.

## 하지 말 것
- 베인 레드를 면(배경)·본문 텍스트에 쓰지 말 것 — 거대 결과 숫자·델타 표시에만.
- 한 슬라이드에 거대 메트릭 2개 이상 금지 — 초점이 분산된다. 메트릭은 슬라이드당 단 하나.
- 그라디언트·그림자·둥근 카드·이모지·클립아트 금지.
- 차트 색을 여러 개 쓰지 말 것 — 무채 명도 + 레드 한 점.
- 좌측 정렬로 회귀하지 말 것 — 중앙 정렬 단일 축이 정체성.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
순백 배경. 캔버스 정중앙(세로 중심선)에 32pt Inter 700 타이틀 중앙 정렬, 1~2줄. 그 위 0.3in 간격으로 14pt 600 대문자 캐치프레이즈("RESULTS DELIVERED" 등) 캡션 그레이. 타이틀 아래 0.4in에 한 줄 16pt 부제. 하단 0.6in 마진에 중앙 정렬 등폭 느낌 메타(클라이언트 · 날짜). 레드는 캐치프레이즈 한 단어 또는 짧은 룰에만.

### 02 · 목차 (agenda)
중앙 정렬 32pt 700 헤더 "성과를 네 단계로 증명한다". 본문 영역 중앙에 `01`~`04` 항목 세로 리스트 — 각 항목은 무채색 번호(28pt 700) + 20pt 항목명, 중앙 정렬, 항목 사이 0.4in. 곁가지 없음, 넓은 좌우 여백. 레드 없음 또는 현재 섹션 번호만 레드.

### 03 · 결과 메트릭 KPI 히어로 (kpi)
순백 배경. 캔버스 상단 28~40% 지점에 거대 결과 메트릭 한 점(`+34%`, 약 130pt Inter 800, 베인 레드, 중앙 정렬). 그 아래 0.2in에 16pt 캡션 그레이 1줄(맥락 — "전환 마진, 18개월"). 캔버스 하단 절반에 보조 KPI 카드 2~3개 가로 균등(각 28pt 700 무채색 수치 + 14pt 라벨). 하단 출처 각주 10pt.

### 04 · Before / After 임팩트 비교 (comparison)
중앙 정렬 32pt 700 헤더. 본문 영역에 중심선 좌우 두 칼럼 — 좌측 `BEFORE` 칼럼(옅은 그레이 패널, 무채색 수치 2~3개), 우측 `AFTER` 칼럼(흰 배경, 레드 결과 수치). 두 칼럼 사이 0.6in 간격, 중앙에 ▲ 레드 델타 삼각형 + 델타 값(28pt 700 레드). 칼럼 헤더 14pt 600 대문자. 하단 출처 각주.

### 05 · 성과 드라이버 본문 (body)
중앙 정렬 32pt 700 헤더. 본문 영역에 3단계 프로세스 플로우 — 좌→우 거대 단계 번호(48pt 800 무채색, 핵심 단계만 레드) + 그 아래 14pt 드라이버 캡션, 단계 사이 1.5pt 가는 화살표. 그 아래 한 줄 20pt 요약 본문 중앙 정렬. 박스 없는 평면.

### 06 · 추이 차트 (chart)
중앙 정렬 32pt 700 헤더. 본문 영역 중앙에 1.5pt 추이 폴리라인(면적 채움 없음) — 시작점 무채색, 최종 결과 시점만 0.16in 레드 원 마커 + 옆에 28pt 레드 델타 라벨. 막대가 필요하면 무채색 막대 + 결과 막대 1개만 레드, 폭:간격 3:2, 베이스라인 0. 값 레이블 14pt 600 직접 표기, 범례 없음. 하단 좌측 10pt 출처·단위 각주.

### 07 · 성과 요약·클로징 (closing)
순백 배경. 캔버스 중앙에 거대 종합 메트릭 한 점(예 `2.7×`, 약 130pt 800 레드) + 16pt 캡션. 그 아래 한 줄 20pt 클로징 스테이트먼트 중앙 정렬. 하단 0.6in 마진에 중앙 정렬 14pt 컨택트 메타. 빌드 애니메이션 없음.
