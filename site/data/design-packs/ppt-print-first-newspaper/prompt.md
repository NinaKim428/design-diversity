# 프린트-퍼스트 뉴스페이퍼 — ppt 디자인 팩

## 이 스타일의 정체성
신문 1면을 슬라이드에 옮긴다. 다단 칼럼 그리드, 굵은 세리프 마스트헤드 헤드라인, 가는 룰 라인으로 기사를 구획한다. 뉴스프린트 크림 톤 지면에 잉크 블랙, 데이트라인·바이라인·킥커 같은 신문 활자 부속이 그대로 살아 있다 — 한눈에 "인쇄된 신문"으로 식별된다.

## 색
- 배경: `#F4F1E8`(뉴스프린트 크림). 표면 변화 없음 — 단일 지면.
- 텍스트: `#1C1B17`(잉크 블랙). 본문은 약간 흐린 `#2E2C26` 허용.
- 강조색 1개만: `#A8231B`(신문 빨강) — 마스트헤드 룰·킥커·핵심 통계에만. 본문 텍스트엔 절대 사용 안 함.
- 그라디언트·면 채움 컬러 블록 금지. 색은 잉크 단색조.

## 타이포그래피
- 마스트헤드/헤드라인: `Playfair Display` Black (대체: `Noto Serif KR ExtraBold`, serif). 표지 마스트헤드 56pt, 본문 헤드라인 36pt. 자간 -0.01em.
- 부제(데크): `Playfair Display` Italic 22pt.
- 본문: `Noto Serif KR` Regular 20pt, 행간 1.4. 다단 칼럼 안에서 흐른다.
- 킥커/바이라인/데이트라인: `Inter` 또는 `Pretendard` 13pt, 대문자, 자간 0.12em — 신문 메타 활자.
- 본문은 양끝 정렬(justify) 허용 — 칼럼의 인쇄 느낌.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 각 0.6in, 상하 각 0.5in — 신문답게 타이트.
- 본문 슬라이드는 3단 또는 4단 칼럼 그리드, 칼럼 간격 0.25in.
- 상단에 마스트헤드 밴드: 마스트헤드 타이틀 + 데이트라인 + 0.5pt 룰 라인 2개로 위아래 구획.
- 헤드라인은 여러 칼럼에 걸쳐(span) 배치, 본문은 칼럼 내 흐름.

## 형태 / 질감
- 룰 라인: 0.5pt(기사 구분)·2pt(섹션 구분) 솔리드 검정 수평/수직선. 신문 구획의 핵심.
- 보더 박스·둥근 모서리·그림자 전부 금지. 면을 가두는 건 룰 라인뿐.
- 이미지: 흑백 그레이스케일 + 미세 하프톤 도트 텍스처(인쇄 망점). 캡션은 13pt 메타 활자, 사진 바로 아래.
- 배경: 미세 종이 그레인 텍스처 오버레이(불투명도 5%).
- 드롭캡: 본문 첫 문단 첫 글자를 3줄 높이 세리프 드롭캡으로.

## 전환 (PPT)
- 전환 없음(None) 또는 즉시 컷 — 인쇄물은 움직이지 않는다. 애니메이션 금지.

## 하지 말 것
- 그라디언트·컬러 면 채움·둥근 모서리 박스·그림자 금지.
- 빨강 외 다른 색 추가 금지. 빨강을 본문 텍스트에 쓰지 말 것.
- 산세리프 헤드라인 금지 — 헤드라인은 세리프. 산세리프는 메타 활자에만.
- 단일 컬럼·중앙 정렬 레이아웃 금지 — 다단 칼럼이 정체성이다.
- 이모지·아이콘·일러스트·클립아트 금지. 시각 요소는 흑백 하프톤 사진뿐.
- 슬라이드를 듬성듬성 비우지 말 것 — 신문답게 칼럼을 채운다.
- **차트 금지사항(아마추어 회귀 차단):** 3D·입체 막대·그림자 금지(인쇄 잉크는 평면). 격자선 금지. 범례 박스 금지 — 직접 레이블링만. 무지개색·컬러 채움 금지 — 잉크 단색조. 둥근 막대 금지(각진 막대만). 잘린 y축 금지. 데이터 영역 테두리 박스 금지. div·표 셀 막대 금지 — SVG 정밀 렌더.

## 차트·데이터 시각화
신문 차트 = 잉크 단색 데이터 + 룰 라인 축 + 세리프 캡션. 신문 인포그래픽 데스크의 활자 부속이 그대로 적용된다. 컬러는 빨강 한 점만 핵심 데이터 강조에.
- **렌더링:** SVG로 정밀하게 그린다. 막대 폭 : 간격 = 3 : 2, 모서리 반경 0(각진 막대). 막대 하단 기준선은 값 0에 정확히 정렬. 잘린 y축 절대 금지(신문 인포그래픽의 신뢰성 핵심).
- **축·격자:** 격자선 완전 제거. x축(기준선)만 0.5pt 룰 라인 `#1C1B17` 솔리드. y축선 제거. 눈금 라벨 최소(0·최댓값) `Inter` 13pt 대문자.
- **데이터 색:** `tokens.json`의 `color.chart`. 막대·선은 잉크 블랙 `#1C1B17` 단색 채움. 비교에서 핵심 막대 1개만 신문 빨강 `#A8231B`. 다계열은 잉크 블랙 + 빨강 + 50% 농도 잉크 그레이로 구분(무지개 금지).
- **값 레이블:** 막대 위·꼭짓점 옆에 직접 표기. `Noto Serif KR` Regular 16pt `#1C1B17`, 탭형 정렬, 일관된 자릿수·단위.
- **직접 레이블링:** 범례 박스 금지. 항목명은 막대 아래, 계열명은 라인 끝에 13pt 대문자 메타 활자(`Inter`)로 직접 붙인다.
- **활자 부속:** 차트 제목은 킥커 활자(`Inter` 13pt 대문자 자간 0.12em). 차트 상단에 0.5pt 룰 라인으로 구획. 출처 각주는 차트 하단 `Inter` 13pt 대문자, "SOURCE —" 프리픽스.
- **차트 타입:** 비교=각진 막대(잉크 단색 + 빨강 강조 1). 추세=1pt 잉크 꺾은선(채움 없음, 꼭짓점 도트 1.5pt). 비중=도넛(조각 3개 이하, 잉크 명도 단계 + 빨강 1조각, 중앙 핵심 수치 세리프 28pt) 또는 100% 누적 막대 1개. 파이 4조각+·다중 도넛 금지.

## 적용 예
- 표지: 크림 지면, 상단 마스트헤드 56pt 세리프 타이틀 + 빨강 0.5pt 룰 + 데이트라인. 그 아래 4단 폭 36pt 헤드라인 + 이탤릭 데크. 좌하단 흑백 하프톤 사진 + 캡션.
- 본문: 마스트헤드 밴드, 그 아래 3단 칼럼. 헤드라인은 2단 span, 본문 20pt 양끝정렬에 드롭캡. 우측 칼럼에 사이드바 통계(빨강 숫자).
- 차트: SVG 신문 인포그래픽풍 각진 막대/꺾은선 차트. 막대는 잉크 블랙 `#1C1B17` 단색 + 핵심 1개만 빨강 `#A8231B`. 막대 폭:간격 = 3:2, 모서리 0. 격자선·범례 제거, x축만 0.5pt 룰 라인, 기준선 0. 값 레이블 16pt `Noto Serif KR` 직접 표기. 차트 제목은 킥커 활자 + 상단 0.5pt 룰, 출처 각주 13pt 대문자 하단 표기.
