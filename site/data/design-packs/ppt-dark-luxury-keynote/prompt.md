# 다크 럭셔리 키노트 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 다크 럭셔리 키노트 — 거의 순흑 무대에 풀블리드 제품/라이프스타일 사진이 떠 있고, 샴페인 골드 0.5pt 헤어라인 프레임이 사진·텍스트 군집을 절제되게 두르며, 넓은 자간의 가는 디스플레이 세리프 라벨이 럭셔리를 만드는 키노트.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 거의 순흑 `#0B0B0C` 무대에 풀블리드 제품/라이프스타일 사진이 한쪽 또는 전면을 채운다, (2) 샴페인 골드 0.5pt 헤어라인이 사진·텍스트 군집을 절제된 프레임으로 두른다 — 절대 면으로 안 쓴다, (3) 가는 디스플레이 세리프(Cormorant Garamond) 라벨이 넓은 자간(0.12em)으로 럭셔리 카탈로그처럼 앉는다. 넓은 여백.

## 색
- 배경 near-black `#0B0B0C`
- 패널 `#1A1A1C`
- 강조 샴페인 골드 `#C9A36A` — 0.5pt 헤어라인 프레임·라벨·차트 핵심 계열에만. 면으로 절대 쓰지 않는다.
- 텍스트 `#EDEAE3`
- 보조 텍스트 `#8E8A82`
- 강조색은 샴페인 골드 1개뿐. 그라디언트·글로우 금지.
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 헤딩·본문 `Cormorant Garamond`(하이콘트라스트 디스플레이 세리프, 대체 `'Times New Roman', serif`). 캡션 `Inter` 300(대체 `Helvetica Neue, sans-serif`). 한글 헤딩은 `Pretendard`(Light), 본문도 `Pretendard`.
- 디스플레이 타이틀: 48~60pt / Cormorant Garamond 500 / 자간 +0.12em / 행간 1.1
- 슬라이드 헤딩: 34pt / Cormorant Garamond 500 / 자간 +0.08em
- 본문: 20pt / Cormorant Garamond 400 / 행간 1.5 / 슬라이드당 5줄 이하
- 캡션·라벨: 11pt / Inter 300 / 자간 +0.2em / 대문자 / 색 보조 텍스트 또는 골드
- KPI 대형 수치: 52pt / Cormorant Garamond 500 / 자간 +0.04em

## 레이아웃 / 그리드
- **풀블리드(airy) + 고정 안전 여백.** 1280×720 기준 콘텐츠 안전 여백 좌·우·상 각 72px, 하단 풋라인 baseline 56px 고정 — 모든 슬라이드 동일. 풀블리드 사진은 마진을 무시하고 엣지투엣지로 가되, 텍스트·헤어라인 모듈은 이 안전 여백 안에 정렬한다.
- 풀블리드 제품/라이프스타일 사진이 슬라이드 한쪽(보통 절반~2/3) 또는 전면. 사진 영역과 텍스트 영역의 경계는 12열 그리드 분할선에 스냅(2/3 분할 = 8열:4열, 절반 = 6열:6열).
- 텍스트 군집은 사진 옆 또는 위, 샴페인 골드 0.5pt 헤어라인 프레임으로 절제되게 두름. 텍스트 좌측 엣지는 덱 전체에서 동일 x. 수직 리듬 24/32/48px 스텝.
- **타이틀 baseline·풋라인 위치 고정.** 슬라이드 헤딩 baseline은 덱 전체에서 동일 y, 풋라인(11pt 캡션 + 페이지 번호)은 하단 baseline 56px에 고정 — 슬라이드마다 위치가 드리프트하지 않는다.
- **두 종류의 슬라이드를 구분한다.** (1) **에디토리얼 슬라이드**(표지·간지·클로징) — 풀블리드 사진 또는 비주얼 필드가 캔버스 전체를 균형 있게 채우고 절제된 텍스트를 얹는다. (2) **콘텐츠 슬라이드**(본문·비교·차트·다이어그램) — 풀블리드 사진은 절반 정도로 두되, 나머지 절반을 0.5pt 골드 헤어라인 프레임으로 구획된 **모듈 3개 이상**(본문 + KPI 카드 또는 데이터 표 + 골드 헤어라인 콜아웃)으로 채운다. "럭셔리하지만 빈약하지 않다" — 콘텐츠 슬라이드는 헤어라인 모듈로 빈 흑면을 채운다.
- **구성 균형 — 죽은 공백 금지.** 캔버스의 어느 한 영역도 ~20%를 넘게 비우지 않는다. 풀블리드 사진이 한쪽을 덜 채우면 그 자리는 따뜻한 조명톤 그라디언트 필드(near-black→`#1A1A1C` 매우 미세한 톤차)·거대 세리프 모노그램·골드 헤어라인 디테일 시스템으로 채운다 — 작은 패널 하나 + 평면 빈 검정 공백은 절대 금지(미완성으로 보인다). 여백은 모듈 사이 호흡으로 의도적으로 분산한다.
- **모듈 좌표 컨벤션:** 콘텐츠 슬라이드는 좌 절반 사진 + 우 절반을 세로 스택(헤딩 + 본문 + KPI 헤어라인 카드 행 + 콜아웃). 모듈은 모두 0.5pt 골드 헤어라인 프레임으로 두름, 모듈 사이 거터 0.25in. 떠다니는(off-grid) 요소 금지 — 모든 모듈이 12열 그리드에 스냅.
- **골드 헤어라인 콜아웃:** 0.5pt 골드 헤어라인 프레임(채움 없음) + 안에 20pt 세리프 인사이트 1~2줄 + 11pt 골드 캡션 라벨. 박스 높이는 내용 높이 + 일관 패딩(상하 좌우 0.2in)으로 — 하단 절반이 비지 않는다. 차트·본문 옆에 1개 두어 해석을 명시.
- **레퍼런스 미세 디테일:** 대문자 캡션·라벨은 자간 +0.12~0.16em, 11~12px, 골드 또는 보조 텍스트. 헤어라인은 덱 전체 0.5pt 일관. 풋라인 룰은 콘텐츠 폭 전체. 모든 콘텐츠 슬라이드는 좌하단 출처 캡션 + 우하단 페이지 번호를 풋라인 baseline에 정렬. 수치는 tabular figures, 소수 자릿수·단위 일관.

## 형태 / 질감
- 모서리 반경 0px. 보더는 0.5pt 골드 헤어라인 프레임만. 그림자·그라디언트·글로우 전면 금지.
- 골드 헤어라인 프레임 — 사진·텍스트 군집을 가는 직사각 라인으로 두름(절대 면 채움 없음).
- 사진은 어둡고 무드 있게(노출 낮춤, 비네트 가능). 패널 `#1A1A1C` 채움.
- 아이콘 거의 안 씀 — 쓴다면 0.75pt 가는 라인 골드 단색.

## 차트·데이터 시각화 (럭셔리 차트 — 순흑 + 골드 헤어라인)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 럭셔리 헤어라인 미감.
- **데이터 색:** 막대·선 기본은 무채색 `#3A3A3C`(연) / `#8E8A82`(진). 강조할 1개만 샴페인 골드 `#C9A36A` 솔리드 또는 골드 헤어라인 윤곽. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 1 : 1(넓은 간격 — 럭셔리 여백). 모서리 0px. 베이스라인 0(잘린 y축 금지). 막대는 헤어라인 윤곽 또는 무채색 솔리드, 강조만 골드.
- **라인 차트:** 0.75pt 골드 헤어라인 폴리라인, 면적 채움 없음, 마커 0.1in 골드 윤곽 원. 럭셔리 헤어라인 미감.
- **데이터 잉크 최소화:** 격자선 전면 제거. 차트 테두리 박스 제거. 축선 0.5pt `#3A3A3C` 또는 생략.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 13pt Inter 300 자간 +0.1em `#EDEAE3`. 범례 박스 금지 — 직접 라벨링.
- **출처:** 차트 하단 좌측 10pt Inter 300 `#8E8A82` 출처·단위 각주.
- **타입 매칭:** 비교=넓은 간격 세로 막대, 추세=골드 헤어라인 라인, 비중=도넛 1개(조각 3개 이하, 0.75pt 헤어라인 분할). 파이 다중·3D 금지.

## 다이어그램·컴포넌트 (럭셔리 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 0.5pt 골드 헤어라인 프레임(채움 없음 또는 패널 `#1A1A1C`), 커넥터는 0.5pt 가는 골드 헤어라인, 단계 번호는 넓은 자간 디스플레이 세리프, 강조는 골드 헤어라인 또는 골드 텍스트.
- **프로세스 플로우:** 좌→우 사각 노드 4~5단계 — 0.5pt 골드 헤어라인 프레임(채움 없음), 노드 사이 0.5pt 가는 골드 헤어라인 커넥터(화살촉 작게). 각 노드에 넓은 자간 세리프 단계 번호. 현재 단계만 골드 헤어라인 1pt로 강조.
- **타임라인:** 수평 축 0.5pt 골드 헤어라인. 마일스톤은 0.1in 골드 윤곽 원(현재 시점만 골드 솔리드). 날짜 라벨 11pt 캡션체 넓은 자간.
- **비교(라인업):** 0.5pt 골드 헤어라인 격자 칼럼 — 헤더 11pt 대문자 골드 캡션체. 각 칼럼에 풀블리드 제품 사진 + 세리프 본문. 우세 칼럼만 0.5pt → 1pt 골드 헤어라인 강조.
- **매트릭스 2×2:** 0.5pt 골드 헤어라인 십자축. 사분면 라벨 세리프 20pt 넓은 자간. 데이터 포인트는 0.12in 골드 윤곽 원(핵심만 골드 솔리드).
- **계층/퍼널:** 폭 비례 사각 적층 — 0.5pt 골드 헤어라인 프레임, 핵심 단만 골드 헤어라인 1pt. 레벨 라벨 우측 세리프 20pt.
- **KPI·스탯 카드:** 0.5pt 골드 헤어라인 프레임 카드(채움 없음 또는 패널), 11pt 대문자 골드 캡션 라벨 + 52pt Cormorant Garamond 500 수치 + 13pt 델타. 카드 3~4개 넓은 간격.
- **목차/섹션 디바이더/인용:** 목차는 넓은 자간 세리프 `01`~`NN` 골드 번호 + 20pt 세리프 항목명 + 0.5pt 골드 헤어라인 구분. 디바이더는 풀블리드 다크 사진 + 0.5pt 골드 헤어라인 프레임 + 중앙 48pt 세리프 섹션명 + 11pt 골드 캡션 번호. 인용은 0.5pt 골드 헤어라인 프레임 + 28pt 세리프 풀쿼트 + 11pt 출처 캡션.

## 전환 (PPT)
subtle — 골드 헤어라인 프레임이 220ms ease-out으로 가늘게 그려지듯 페이드 인, 풀블리드 사진은 250ms 페이드. 우아하고 절제되게, 슬라이드·바운스·글로우 금지.

## 하지 말 것
- 골드를 큰 면·버튼 배경으로 쓰지 말 것 — 0.5pt 헤어라인 프레임·라벨·차트 핵심 계열에만.
- 산세리프 헤딩 금지 — 디스플레이 세리프(Cormorant Garamond)가 정체성(시네마틱 다크 팩과의 분리선).
- 글로우·그라디언트·그림자·둥근 모서리·이모지 금지.
- 사진 없이 텍스트만으로 채우지 말 것 — 풀블리드 비주얼이 정체성.
- 자간을 좁게 쓰지 말 것 — 라벨은 넓은 자간(0.12~0.2em)이 럭셔리.
- 차트 회귀: 3D, 무지개색, 격자선, 범례 박스, 잘린 y축, 출처 누락.
- **콘텐츠 슬라이드(본문·비교·차트)를 사진 하나 + 텍스트 한 줄로 비우기 금지.** 에디토리얼 미감은 표지·간지·클로징에서 유지하되, 콘텐츠 슬라이드는 골드 헤어라인 모듈 3개 이상으로 채운다 — "럭셔리하지만 빈약하지 않다". 모든 본문성 슬라이드에 출처 캡션 + 페이지 번호.
- **캔버스 한 구석에 죽은 평면 검정 공백을 고이게 두지 말 것** — 특히 표지의 작은 패널 + 우측 평면 빈 검정 구성은 절대 금지. 빈 영역은 따뜻한 조명톤 그라디언트 필드·거대 세리프 모노그램·골드 헤어라인 디테일로 채운다.
- **빈 골드 헤어라인 플레이스홀더 프레임 금지** — 비주얼/이미지 프레임은 반드시 실제 렌더된 비주얼(다크 무드 사진·톤 그라디언트 필드·차트·다이어그램·모노그램)을 담는다.
- **헤드라인 문장 중간 단어 비대 금지** — 디스플레이 타이틀은 일관 크기, 강조는 골드 색·자간으로.
- **여백·풋라인·타이틀 baseline 위치 드리프트 금지** — 슬라이드마다 동일 y에 고정.

## 상세 페이지 (6종)

### 01 · 표지 (cover)
near-black 전면. 표지는 (a) 풀블리드 구성 — 캔버스 전체에 풀블리드 다크 제품/라이프스타일 사진(노출 낮춤)이 초점 영역을 이루고, 좌측 1/3에 0.5pt 골드 헤어라인 프레임으로 두른 텍스트 군집을 사진 위에 직접 얹는다. 또는 (b) 슬라이드 전체 높이를 채우는 골드 헤어라인 프레임 구성 — 좌측에 텍스트 군집, 우측 빈 영역은 평면 검정으로 두지 말고 따뜻한 조명톤 그라디언트 필드(near-black→`#1A1A1C` 미세 톤차, 위→아래 또는 코너 방향) + 거대 Cormorant Garamond 세리프 모노그램(브랜드 이니셜, 화면 높이의 60~70%, `#1A1A1C`보다 한 단계 밝은 톤온톤) + 골드 헤어라인 디테일 시스템(코너 브래킷·수직 헤어라인 1~2줄)으로 채운다. **작은 패널 + 평면 빈 검정 공백은 절대 금지** — 우측이 평평하게 비면 누가 봐도 깨져 보인다. 텍스트 군집: 11pt 골드 대문자 라벨(자간 0.16em) + 거대 54pt Cormorant Garamond 500 타이틀(자간 0.12em, 2줄 이내) + 20pt 세리프 부제 + 그 아래 골드 헤어라인 메타 미니 행(`HOUSE` · `SEASON` · `DATE` 11pt 캡션체, 자간 0.16em, 셀 사이 0.5pt 골드 헤어라인 구분). 텍스트 좌측 엣지는 안전 여백 72px x. 하단 baseline 56px에 11pt 캡션 메타 + 페이지 번호.

### 02 · 섹션 간지 (section-divider)
near-black 전면에 풀블리드 다크 무드 사진(캔버스 전체를 채우는 풀블리드 — 빈 평면 검정 영역 없음). 사진 위 중앙에 0.5pt 골드 헤어라인 프레임 + 그 안에 11pt 골드 캡션 섹션 번호(`SECTION 02`, 자간 0.16em) + 48pt Cormorant Garamond 500 섹션명(자간 0.12em) + 그 아래 이 섹션 항목 3개를 골드 헤어라인 구분 미니 인덱스(11pt 캡션체)로. 사진이 캔버스를 덜 채우면 그 영역은 따뜻한 조명톤 그라디언트 필드로 채워 평면 검정 공백을 만들지 않는다. 하단 baseline 56px에 페이지 번호. 간지는 에디토리얼 — 절제 유지하되 항목 인덱스로 하단을 채운다.

### 03 · 제품 디테일 본문 (body)
near-black 배경. 좌측 절반(6열)에 풀블리드 제품 사진(0.5pt 골드 헤어라인 프레임으로 두름, 슬라이드 전체 높이를 채움). 우측 절반(6열, 안전 여백 안)을 세로 스택 — 34pt 세리프 헤딩(baseline 고정) + 11pt 골드 대문자 라벨(자간 0.16em) + 20pt 세리프 본문 3~4줄(핵심 구절 골드) + 3블록 디테일 분해(각 블록: 골드 세리프 번호 + 14pt 600 미니헤더 + 14pt 근거 2개, 블록 사이 0.5pt 골드 헤어라인) + KPI 헤어라인 카드 행 2~3개(52pt 세리프 tabular 수치 + 11pt 골드 라벨) + 골드 헤어라인 콜아웃 1개(내용 높이 + 0.2in 패딩, 하단이 비지 않게). 모듈 4개 이상, 모두 0.5pt 골드 헤어라인 프레임, 12열 그리드에 스냅, 모듈 사이 거터 0.25in, 수직 리듬 24/32/48px. 우측 영역에 죽은 검정 공백이 남지 않게 모듈로 채운다. 하단 baseline 56px에 11pt 출처 캡션(좌) + 페이지 번호(우).

### 04 · 룩북 갤러리 (gallery)
near-black 배경. 상단 34pt 세리프 헤딩 + 11pt 골드 라벨. 본문 영역에 풀블리드 다크 제품 사진 3~4개를 0.5pt 골드 헤어라인 프레임으로 각각 두르고 비대칭 블록 그리드로 배치(크기 가변). 각 프레임 아래 11pt 캡션체 넓은 자간 라벨 + 핵심 수치. 갤러리는 사진이 모듈 — 에디토리얼 절제 허용. 하단 페이지 번호.

### 05 · 라인업 비교 (comparison)
near-black 배경. 상단 34pt 세리프 헤딩 + 11pt 골드 라벨. 본문 영역에 0.5pt 골드 헤어라인 격자 칼럼 2~3개 — 각 칼럼에 풀블리드 제품 사진 + 11pt 골드 대문자 헤더 + 본격 비교 항목 4~6행(행라벨 + 수치, 0.5pt 골드 헤어라인 행 구분, 우세 셀 골드 텍스트) + 52pt 세리프 핵심 수치. 우세 칼럼만 1pt 골드 헤어라인 강조. 본문 하단에 골드 헤어라인 평결 프레임(종합 평결 20pt 세리프 + 핵심 수치). 하단 10pt 출처 각주 + 페이지 번호.

### 06 · 클로징 (closing)
near-black 전면에 풀블리드 다크 무드 사진. 중앙에 0.5pt 골드 헤어라인 프레임 + 그 안에 34pt Cormorant Garamond 500 클로징 스테이트먼트(자간 0.08em) + 다음 단계 3개를 골드 헤어라인 구분 미니 리스트(14pt 세리프)로 + 11pt 골드 대문자 컨택트 라벨(자간 0.2em). 넓은 여백 + 페이지 번호.
