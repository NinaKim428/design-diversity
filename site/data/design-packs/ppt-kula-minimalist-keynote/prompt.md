# Kula 미니멀리스트 키노트 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. Kula 미니멀리스트 키노트 — 따뜻한 샌드 배경에 둥근 모서리(16~24px) 이미지 프레임이 모듈러 블록 그리드로 정렬되고, 작은 산세리프 캡션이 도록처럼 단정한 차분한 룩북/포트폴리오 키노트. 더스티 뉴트럴 톤, dusty clay 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 따뜻한 샌드 `#EDE8E0` 배경에 둥근 모서리(16~24px) 이미지 프레임 — 이미지가 모듈러 블록 그리드로 갤러리처럼 정렬, (2) 채도 낮은 더스티 뉴트럴 색만 — 채도 높은 색 일절 없음, (3) 작은 산세리프 캡션이 미술 도록처럼 단정하고 여백이 넓다. 부드럽고 차분한 룩북.

## 색
- 배경 샌드 `#EDE8E0`
- 표면(이미지 프레임·카드) `#FFFFFF`
- 따뜻한 잉크 `#4A4540`
- 강조 dusty clay `#B79B86` — 캡션 강조·작은 라벨·차트 핵심 계열에만. 채도 낮은 한 톤.
- 캡션 `#8C857C`
- 강조색은 dusty clay 1개뿐. 채도 높은 색·그라디언트 금지.
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 전부 `Plus Jakarta Sans`(대체 `Hanken Grotesk, Helvetica Neue, sans-serif`). 한글은 `Pretendard`.
- 슬라이드 헤딩: 34pt / Plus Jakarta Sans 600 / 자간 -1% / 행간 1.2
- 부제: 20pt / Plus Jakarta Sans 400 / 색 따뜻한 잉크
- 본문: 18pt / Plus Jakarta Sans 400 / 행간 1.5 / 슬라이드당 6줄 이하
- 도록 캡션: 12pt / Plus Jakarta Sans 500 / 자간 +4% / 색 캡션
- 작은 라벨: 11pt / Plus Jakarta Sans 600 / 자간 +8% / 대문자 / 색 dusty clay
- KPI 대형 수치: 44pt / Plus Jakarta Sans 600 / tabular numerals

## 레이아웃 / 그리드
- **모듈러 블록 그리드(airy).** 좌우 마진 각 0.75in, 상하 0.6in. 12열 그리드를 큰 블록 모듈로 묶어 이미지·텍스트 배치.
- 둥근 모서리 이미지 프레임을 2~6개 블록 그리드로 정렬(갤러리/룩북 페이지).
- 캡션은 이미지 프레임 아래 12pt로 도록처럼 단정하게.
- **밀도 원칙(절제 ≠ 빈약):** 미니멀 룩북이지만 본문 슬라이드가 비어도 된다는 뜻이 아니다 — 차분한 톤을 유지하되 둥근 흰 카드 모듈을 **3개 이상** 모듈러 그리드에 정렬해 캔버스 82% 이상을 채운다. 여백은 모듈 사이 호흡으로 두되, "거대한 샌드 여백에 카드 하나"는 금지(표지·간지 예외).
- **모듈 좌표 컨벤션:** 12열을 6:6 또는 4:4:4 블록으로 — 한쪽에 헤딩+본문, 다른 쪽에 둥근 카드 모듈 묶음(KPI 카드 또는 데이터 표 또는 이미지 프레임). 모듈 사이 거터 0.3in.
- **도록 콜아웃 카드:** 둥근 흰 카드(반경 16px) + 11pt 대문자 clay 라벨 + 16pt 인사이트 1~2줄. 차트·본문 옆에 1개 두어 절제된 인사이트를 명시.

## 형태 / 질감
- 이미지 프레임만 둥근 모서리(16~24px radius). 텍스트 박스는 보더 없음, 모서리 0px.
- 그림자 없거나 아주 옅게(0~4px blur, 4% opacity 이하).
- dusty clay는 캡션 강조·작은 라벨·룰에만 — 큰 면으로 절제.
- 아이콘은 1.5pt 가는 라인 단색 더스티. 풀블리드 사진 금지(이미지는 둥근 프레임 안에).

## 차트·데이터 시각화 (룩북 차트 — 더스티 뉴트럴 + clay 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 차분한 룩북 미감.
- **데이터 색:** 막대·선 기본은 더스티 뉴트럴 `#D3CABF`(연) / `#8C857C`(진). 강조할 1개만 dusty clay `#B79B86` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 4px(차트 막대만 살짝 둥글게 — 부드러운 룩북 톤). 베이스라인 0(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#D3CABF`). 차트 테두리 박스 제거. x축선 0.75pt `#8C857C`.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 14pt Plus Jakarta Sans 600 tabular. 범례 박스 금지 — 직접 라벨링.
- **출처:** 차트 하단 좌측 12pt Plus Jakarta Sans `#8C857C` 출처·단위 각주.
- **타입 매칭:** 비교=세로 막대, 추세=1.5pt 폴리라인(clay, 면적 채움 없음), 비중=도넛 1개(조각 3개 이하, 둥근 룩북 톤). 파이 다중·3D 금지.

## 다이어그램·컴포넌트 (룩북 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 둥근 모서리(12~16px) 흰 카드, 보더 없음 또는 아주 옅은 그림자, 커넥터는 1.5pt 부드러운 곡선/직선, 단계 번호는 작은 clay 원, 강조는 dusty clay 텍스트·작은 룰.
- **프로세스 플로우:** 좌→우 둥근 카드 노드 4~5단계(반경 12~16px, 흰 채움) — 노드 사이 1.5pt 부드러운 직선 커넥터(화살촉 작게). 각 노드 좌상단 작은 0.3in clay 원 단계 번호. 핵심 단계만 카드 좌측 0.08in clay 룰.
- **타임라인:** 수평 축 0.75pt `#8C857C`. 마일스톤은 0.12in 더스티 뉴트럴 원(현재 시점만 clay 솔리드). 날짜 라벨 12pt 도록 캡션체.
- **비교(2~3열):** 둥근 카드 칼럼(반경 16px, 흰 채움) 2~3개 — 칼럼 사이 0.5in 간격, 보더 없음. 헤더 11pt 대문자 clay. 우세 칼럼만 상단 0.08in clay 룰.
- **매트릭스 2×2:** 0.75pt 더스티 십자축. 사분면 라벨 도록 캡션체 12pt. 데이터 포인트는 0.14in 더스티 원(핵심만 clay 솔리드). 부드러운 배치.
- **계층/퍼널:** 둥근 사각 적층(반경 12px), 폭 비례 — 더스티 명도 단계, 핵심 단만 clay. 레벨 라벨 우측 18pt.
- **KPI·스탯 카드:** 둥근 흰 카드(반경 16px), 11pt 대문자 clay 라벨 + 44pt Plus Jakarta Sans 600 따뜻한 잉크 수치 + 14pt 델타. 카드 3~4개 가로 균등, 넓은 간격.
- **목차/섹션 디바이더/인용:** 목차는 작은 clay 원 번호 + 18pt 항목명, 항목 사이 넓은 간격. 디바이더는 샌드 배경 + 둥근 이미지 프레임 1점 + 34pt 섹션명 + 11pt clay 섹션 번호. 인용은 둥근 흰 카드 + 24pt 600 풀쿼트 + 12pt 도록 출처 캡션.

## 전환 (PPT)
subtle — 둥근 이미지 프레임·카드가 200ms ease-out으로 부드럽게 페이드 인하는 정도만. 슬라이드·바운스 모션 금지.

## 하지 말 것
- 채도 높은 색 금지 — 더스티 뉴트럴만(채도 높은 색은 다른 팩의 자리).
- 풀블리드 사진 금지 — 이미지는 둥근 모서리 프레임 안에(풀블리드는 warm-hospitality의 자리).
- 짙은 그림자·글로우·그라디언트 금지(그림자는 아주 옅게만).
- 강조색 2개 이상 금지 — dusty clay 한 톤.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축.
- **거대한 샌드 여백에 카드/차트 하나만 두고 비우기 금지(표지·간지·갤러리 예외).** 절제 ≠ 빈약 — 본문/비교/차트 슬라이드는 둥근 카드 모듈 3개 이상으로 채운다. 모든 본문성 슬라이드에 도록 출처 캡션 + 페이지 번호.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
샌드 `#EDE8E0` 배경. 좌측 6열에 11pt clay 대문자 라벨 + 그 아래 34pt → 44pt로 키운 600 타이틀 2~3줄 + 20pt 부제 + 그 아래 도록 메타 미니 스트립(`STUDIO` · `DATE` · `EDITION` 12pt 캡션체). 우측 6열에 둥근 모서리(20px) 이미지 프레임 1점(세로 비율). 넓은 여백. 하단 12pt 도록 메타 캡션 + 페이지 번호. 표지는 절제 허용.

### 02 · 목차 (agenda)
샌드 배경. 상단 11pt clay 라벨 + 34pt 600 헤딩 `Contents`. 본문 영역 좌측 7열에 `01`~`05` 목차 — 작은 0.3in clay 원 번호 + 18pt 항목명 + 그 아래 12pt 캡션체 한 줄 설명 + 우측 끝 12pt 페이지 번호, 항목 사이 0.4in 간격 + 현재 섹션 좌측 0.08in clay 룰(진행 인디케이터). 우측 5열에 둥근 흰 카드 — 본 덱 한 줄 요지(18pt) + 둥근 이미지 프레임 1점. 넓은 여백.

### 03 · 핵심 본문 (body)
샌드 배경. 좌측 6열에 34pt 헤딩 + 18pt 리드 1줄 + 3블록 분해(각 블록: 작은 clay 원 번호 + 14pt 600 미니헤더 + 14pt 근거 2개 + 블록 하단 메트릭 28pt 600 tabular + 14pt 라벨). 우측 6열을 상하 2단 — 상단에 둥근 모서리(20px) 이미지 프레임 1점 또는 보조 막대 차트, 하단에 도록 콜아웃 카드(둥근 흰 카드 + clay 라벨 + 16pt 인사이트). 넓은 여백이되 모듈 4개 이상. 하단 12pt 도록 캡션 + 페이지 번호.

### 04 · 룩북 이미지 갤러리 (gallery)
샌드 배경. 상단 34pt 헤딩 + 11pt clay 라벨. 본문 영역에 둥근 모서리(16~24px) 이미지 프레임 4~6개를 모듈러 블록 그리드로 정렬(크기 가변 — 일부 큰 블록, 일부 작은 블록). 각 프레임 아래 12pt 도록 캡션. 프레임 사이 0.3in 간격, 보더 없음. 갤러리는 이미지가 모듈 — 절제 허용.

### 05 · KPI 룩북 (kpi)
샌드 배경. 상단 34pt 헤딩 + 11pt clay 라벨. 본문 영역에 둥근 흰 카드(반경 16px) KPI 4~6개 그리드 — 각 카드: 11pt 대문자 clay 라벨 + 44pt Plus Jakarta Sans 600 따뜻한 잉크 수치 + 14pt 델타 + 가는 더스티 미니 스파크라인 + 12pt 캡션체 맥락 1줄. 카드 사이 넓은 간격. 그 옆 보조 차트 1개 또는 도록 콜아웃 카드. 하단 12pt 출처 캡션 + 페이지 번호.

### 06 · 옵션 비교 (comparison)
샌드 배경. 상단 34pt 헤딩 + 11pt clay 라벨. 본문 영역에 둥근 흰 카드 칼럼(반경 16px) 2~3개 — 각 칼럼 상단에 11pt 대문자 clay 헤더 + 둥근 이미지 프레임 + 18pt 본문 + 본격 비교 항목 4~6행(행라벨 + 수치, 우세 셀 clay). 칼럼 사이 0.5in 간격. 우세 칼럼만 상단 0.08in clay 룰. 본문 하단에 둥근 흰 평결 카드(종합 평결 28pt 600 + 14pt 평결 1줄). 하단 12pt 출처 캡션 + 페이지 번호.

### 07 · 클로징 (closing)
샌드 배경. 좌측 6열에 34pt 600 클로징 스테이트먼트 + 20pt 부제 + 다음 단계 3개(작은 clay 원 번호 + 18pt 라벨) + 11pt clay 컨택트 라벨. 우측 6열에 둥근 모서리(20px) 이미지 프레임 1점. 넓은 여백 + 페이지 번호.
