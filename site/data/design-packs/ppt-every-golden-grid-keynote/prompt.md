# Every 골든 그리드 키노트 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. Every 골든 그리드 키노트 — 황금비(1:1.618)로 분할된 그리드가 모든 슬라이드의 골격이고, 이미지 블록·텍스트 컬럼·여백·폰트 크기까지 전부 황금 스케일을 따르는 비례 일관성의 미니멀 키노트. 무채색 + muted gold 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 모든 슬라이드가 큰 블록 1.618 : 작은 블록 1로 분할되고 그 안이 다시 황금비로 재분할된다 — 균등 12열이 아니다, (2) 폰트 크기도 황금 스케일(13/21/34/55pt) — 인접 크기 비율이 1.618, (3) 무채색 캔버스에 차분한 muted gold `#B5A642` 단 한 점. 황금나선 가이드가 콘텐츠 무게중심에 맞는 비례 미감.

## 색
- 배경 `#FAFAF8` (따뜻한 오프화이트)
- 본문 잉크/헤딩 `#161616`
- 강조 muted gold `#B5A642` — 라벨·차트 핵심 계열·작은 룰에만. 채도 낮은 골드 한 점.
- 그리드 라인 `#D8D8D2` (1px, 옅게 노출 가능)
- 본문 그레이 `#6E6E68`
- 강조색은 muted gold 1개뿐. 그라디언트·다른 컬러 금지.

## 타이포그래피
- 폰트: 전부 `Inter`(대체 `Helvetica Neue, sans-serif`). 한글은 `Pretendard`.
- **황금 스케일** — 인접 크기 비율 1.618: 캡션 13pt / 본문 21pt / 부제 34pt / 헤딩 55pt. (작은 덱은 13/21/34, 큰 헤딩 슬라이드만 55pt.)
- 슬라이드 헤딩: 34pt 또는 55pt / Inter 600 / 자간 -1% / 행간 1.15
- 본문: 21pt / Inter 400 / 행간 1.5(=21×1.618÷2 근사) / 슬라이드당 6줄 이하
- 캡션·라벨: 13pt / Inter 500 / 자간 +4% / 색 본문 그레이 또는 골드
- KPI 대형 수치: 55pt / Inter 600 / tabular numerals

## 레이아웃 / 그리드
- **황금비 블록 그리드(balanced).** 좌우 마진 각 0.62in, 상하 0.5in. 슬라이드를 큰 블록 : 작은 블록 = 1.618 : 1로 분할(가로 또는 세로). 큰 블록을 다시 1.618 : 1로 재분할 가능.
- 콘텐츠 무게중심을 황금나선 초점(슬라이드 폭의 약 61.8% / 38.2% 교차점)에 맞춘다.
- 이미지 블록·텍스트 컬럼·여백이 전부 황금비. 임의 크기 금지 — 비례 일관성이 정체성.
- 1px 그리드 라인 `#D8D8D2`을 배경에 옅게 노출 가능(가이드처럼).

## 형태 / 질감
- 모서리 반경 0px(각진 블록). 보더는 1px 그리드 라인 `#D8D8D2`. 그림자·그라디언트 전면 금지.
- 이미지는 직사각형, 황금비 비율의 블록에 꽉 차게(클립 없음).
- muted gold는 작은 라벨·룰·차트 핵심 계열에만 — 면으로 쓰지 않는다. 아이콘 거의 안 씀.

## 차트·데이터 시각화 (비례 차트 — 무채 + 골드 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 황금비 블록 안에 비례적으로 앉는다.
- **데이터 색:** 막대·선 기본은 무채색 `#C4C4BE`(연) / `#6E6E68`(진). 강조할 1개만 muted gold `#B5A642` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 1.618 : 1(황금비). 모서리 0px. 베이스라인 0에서 정확히(잘린 y축 금지).
- **차트 블록 크기:** 차트 영역 자체가 황금비 직사각형(폭:높이 = 1.618:1).
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#D8D8D2`). 차트 테두리 박스 제거. x축선 0.75pt `#6E6E68`.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 13pt Inter 500 tabular. 범례 박스 금지 — 직접 라벨링.
- **출처:** 차트 하단 좌측 13pt Inter `#6E6E68` 출처·단위 각주.
- **타입 매칭:** 비교=세로 막대, 추세=1pt 폴리라인(면적 없음), 비중=도넛 1개(조각 3개 이하). 파이 다중·3D 금지.

## 다이어그램·컴포넌트 (황금비 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 황금비 직사각형 블록, 보더 1px 그리드 라인, 커넥터는 1pt 가는 라인, 노드·간격 크기가 황금비, 강조는 muted gold 텍스트·작은 룰.
- **프로세스 플로우:** 좌→우 사각 노드 — 노드 크기 황금비 직사각형, 노드 폭 : 간격 = 1.618 : 1, 1px 그리드 라인 보더. 노드 사이 1pt 가는 라인 커넥터. 단계 번호는 13pt 골드. 핵심 단계만 좌측 0.08in 골드 룰.
- **타임라인:** 수평 축 0.75pt `#6E6E68`. 마일스톤 간격이 황금비로 증감. 마커는 0.12in 무채색 원(현재 시점만 골드). 라벨 13pt.
- **비교(2~3열):** 칼럼 폭이 황금비(1.618:1 또는 균등 황금 재분할). 1px 그리드 라인 구분. 헤더 13pt 500. 우세 열만 골드 텍스트.
- **매트릭스 2×2:** 십자축을 황금비 위치(61.8%)에 두는 비대칭 2×2 — 0.75pt 그리드 라인. 데이터 포인트 0.12in 점(핵심만 골드). 사분면 라벨 13pt.
- **계층/퍼널:** 단 폭이 황금비로 감소하는 적층. 무채색 명도, 핵심 단만 골드. 레벨 라벨 우측 21pt.
- **KPI·스탯 카드:** 황금비 직사각형 카드, 1px 그리드 라인 보더, 13pt 라벨 + 55pt Inter 600 수치 + 13pt 골드 델타. 카드 크기·간격 황금비.
- **목차/섹션 디바이더/인용:** 목차는 `01`~`NN` 골드 번호 + 21pt 항목명, 행 간격 황금비. 디바이더는 황금나선 초점에 거대 55pt 헤딩 + 13pt 골드 섹션 번호. 인용은 황금비 블록에 34pt 풀쿼트 + 13pt 출처.

## 전환 (PPT)
subtle — 황금비 블록이 200ms ease-out으로 짧게 페이드 인하는 정도만. 슬라이드·바운스 모션 금지.

## 하지 말 것
- 균등 12열 그리드로 회귀 금지 — 황금비 분할이 정체성(균등 그리드는 다른 팩의 자리).
- 요소를 황금비 무시하고 임의 크기·위치에 두지 말 것 — 비례 일관성이 정체성.
- 그라디언트·그림자·둥근 카드·이모지·클립아트 금지.
- 강조색 2개 이상 금지 — muted gold 한 점.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축.

## 상세 페이지 (6종)

### 01 · 표지 (cover)
오프화이트 배경. 슬라이드를 세로로 큰 블록(상단 61.8%) : 작은 블록(하단 38.2%)로 분할. 큰 블록 안 황금나선 초점(폭 61.8% 지점)에 55pt 600 타이틀. 작은 블록에 13pt 골드 라벨 + 21pt 부제. 1px 그리드 라인을 옅게 노출. 우하단에 13pt 메타. 골드는 라벨에만.

### 02 · 목차 (agenda)
슬라이드를 가로로 큰 블록(좌 61.8%) : 작은 블록(우 38.2%)로 분할. 좌측에 `01`~`05` 목차 — 골드 번호 13pt + 21pt 항목명, 행 간격이 황금비로 증감. 우측 작은 블록에 34pt 섹션 헤딩 + 옅은 그리드 라인. 상단 13pt 라벨.

### 03 · 섹션 간지 (section-divider)
오프화이트 전면. 황금나선 초점(폭 61.8% / 높이 38.2% 교차점)에 거대 55pt 600 섹션명. 그 위 13pt 골드 섹션 번호(`02 ─`). 1px 그리드 라인으로 황금비 분할선을 옅게 노출. 나머지 광활한 여백.

### 04 · 핵심 본문 (황금비 블록) (body)
슬라이드를 가로 1.618:1 분할 — 큰 블록(좌)에 34pt 헤딩 + 21pt 본문 4~5줄, 작은 블록(우)에 황금비 이미지 블록 또는 KPI 카드. 큰 블록을 다시 황금비로 재분할해 헤딩과 본문을 배치. 1px 그리드 라인 노출. 하단 13pt 캡션.

### 05 · 비례 차트 (chart)
가로 1.618:1 분할 — 큰 블록에 차트(폭:높이 1.618:1 직사각형, 막대 폭:간격 1.618:1, 무채색 + 강조 1막대 골드, 베이스라인 0, 13pt 값 레이블 직접 표기), 작은 블록에 21pt 차트 해석 + 13pt 출처 각주. 범례 없이 직접 라벨링.

### 06 · 클로징 (closing)
세로 큰 블록 : 작은 블록 분할. 큰 블록 황금나선 초점에 34pt 클로징 스테이트먼트. 작은 블록에 KPI 카드 1~2개(55pt 수치) 또는 13pt 컨택트 메타 + 골드 룰. 1px 그리드 라인 옅게.
