# Epoch 프리미엄 키노트 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. Epoch 프리미엄 키노트 — 차분한 딥 슬레이트 배경에 가는 세리프 헤딩과 산세리프 본문을 혼합하고, 1pt 룰 라인이 콘텐츠를 정연히 구획하는 차갑고 모던한 하이엔드 코퍼레이트 키노트. 강조는 cool steel 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 딥 슬레이트 `#1A1E26` 배경 — 따뜻하지 않은 차가운 다크, (2) 가는 트랜지셔널 세리프 헤딩 + 산세리프 본문의 절제된 혼합 타이포, (3) 1pt 룰 라인이 헤더·섹션·콘텐츠를 정연히 구획하고 cool steel `#7FA9C9`이 차트·라벨에 차갑게 한 점. heritage 럭셔리와 달리 따뜻함 없이 정제된 코퍼레이트.

## 색
- 배경 딥 슬레이트 `#1A1E26`
- 룰/패널 `#2C313B`
- 강조 cool steel `#7FA9C9` — 차트 시리즈·강조 라벨·작은 룰에만. 차가운 한 점, 면으로 절제.
- 텍스트 `#E6E8EC`
- 보조 텍스트 `#9298A4`
- 강조색은 cool steel 1개뿐. 골드·따뜻한 강조·그라디언트 금지.
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 헤딩 `Newsreader`(트랜지셔널 세리프, 대체 `Georgia, serif`). 본문 `Inter`(대체 `Helvetica Neue, sans-serif`). 한글 헤딩은 `Pretendard`(Medium), 본문도 `Pretendard`.
- 슬라이드 헤딩: 30pt / Newsreader 500 / 자간 0 / 행간 1.2 / 색 텍스트
- 섹션 라벨: 11pt / Inter 500 / 자간 +8% / 대문자 / 색 cool steel
- 본문: 17pt / Inter 400 / 행간 1.45 / 슬라이드당 6줄 이하
- 캡션: 12pt / Inter 400 / 색 보조 텍스트
- KPI 대형 수치: 42pt / Newsreader 500
- 표 숫자: 14pt / Inter 400 / tabular numerals

## 레이아웃 / 그리드
- **중앙 정렬 축(balanced).** 좌우 마진 각 0.7in, 상하 0.55in. 12열 그리드, 핵심 콘텐츠는 캔버스 중심선 기준 정렬 경향.
- 슬라이드 상단: 11pt cool steel 섹션 라벨 + 30pt 세리프 헤딩 + 그 아래 1pt 룰 라인 `#2C313B`.
- 1pt 룰 라인이 콘텐츠 구획 장치 — 섹션 분리·표 행·카드 경계.
- **밀도 원칙:** 정연한 코퍼레이트 미감이라고 슬라이드가 비어도 된다는 뜻이 아니다 — 1pt 룰로 구획된 **모듈 3개 이상**(본문 분해 + 차트/표 + KPI 카드 또는 콜아웃)이 한 슬라이드에 정연히 공존한다. 본문 슬라이드는 캔버스 87% 이상을 의미 있는 모듈로 채운다. 거대 슬레이트 여백에 차트 하나만 띄우는 것 금지.
- **모듈 좌표 컨벤션:** 6:6 분할(좌 본문 + 우 차트/카드) 또는 헤더 하단 풀폭 차트 + 그 아래 1pt 룰 + KPI 스트립의 상하 2단. 모듈 사이 거터 0.2in, 경계는 1pt 룰.
- **콜아웃 모듈:** 슬레이트 패널 `#2C313B` + 좌측 1pt steel 룰, 안에 14pt 인사이트 1~2줄 + 11pt steel 라벨. 차트·표 옆에 1개 두어 해석을 명시.

## 형태 / 질감
- 모서리 반경 0px(각진). 보더는 1pt 룰 라인 `#2C313B`(두껍게 쓰지 말 것). 그림자·그라디언트·글로우 전면 금지.
- 패널은 `#2C313B` 채움. cool steel은 면으로 절제 — 라벨·차트·룰에.
- 아이콘은 1pt 가는 라인 단색 steel. 정제된 평면.

## 차트·데이터 시각화 (코퍼레이트 차트 — 슬레이트 + steel 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 차갑고 정제된 코퍼레이트 미감.
- **데이터 색:** 막대·선 기본은 무채색 슬레이트 `#4A5160`(연) / `#9298A4`(진). 강조할 1개만 cool steel `#7FA9C9` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px. 베이스라인 0(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선은 y축 주요 눈금 2~3개 0.5pt `#2C313B`만. 차트 테두리 박스 제거. x축선 0.75pt `#9298A4`.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 14pt Inter 400 tabular `#E6E8EC`. 범례 박스 금지 — 직접 라벨링.
- **출처:** 차트 하단 좌측 12pt Inter `#9298A4` 출처·단위 각주.
- **타입 매칭:** 비교=세로 막대, 추세=1pt 폴리라인(steel, 면적 채움 없거나 steel 8%), 비중=도넛 1개(조각 3개 이하). 파이 다중·3D 금지.

## 다이어그램·컴포넌트 (코퍼레이트 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진(반경 0px) 슬레이트 패널 `#2C313B`, 1pt 룰 라인 보더, 커넥터는 1pt 가는 라인(작은 셰브론 화살촉), 단계 번호는 작은 steel 텍스트, 강조는 cool steel 텍스트·1pt steel 룰.
- **프로세스 플로우:** 좌→우 사각 노드 4~5단계 — 슬레이트 패널 + 1pt 룰 보더, 노드 사이 1pt 가는 셰브론. 각 노드 좌상단 11pt steel 단계 번호. 현재 단계만 좌측 1pt steel 룰.
- **타임라인:** 수평 축 0.75pt `#9298A4`. 마일스톤은 0.12in steel 윤곽 원(현재 시점만 steel 솔리드). 날짜 라벨 축 아래 12pt, 사건 라벨 축 위 세리프 14pt.
- **비교(2~3열):** 1pt 룰 라인 격자 칼럼 — 헤더 행 11pt 대문자 + 하단 1pt steel 룰. 수치 셀 등폭 우정렬. 우세 칼럼만 헤더 steel 텍스트.
- **매트릭스 2×2:** 1pt 룰 라인 십자축. 사분면 라벨 세리프 14pt. 데이터 포인트는 0.14in steel 윤곽 원(핵심만 steel 솔리드). 축 라벨 바깥 11pt 보조 텍스트.
- **계층/퍼널:** 폭 비례 사각 적층 — 슬레이트 명도 단계, 핵심 단만 steel 룰. 레벨 라벨 우측 세리프 14pt.
- **KPI·스탯 카드:** 슬레이트 패널 + 1pt 룰 보더, 11pt 대문자 라벨 + 42pt Newsreader 500 텍스트 수치 + 14pt steel 델타. 카드 3~4개 가로 균등, 1pt 룰 구분.
- **목차/섹션 디바이더/인용:** 목차는 `01`~`NN` steel 번호 + 세리프 항목명 + 1pt 룰 구분 + 페이지 번호. 디바이더는 슬레이트 전면 + 중앙 거대 80pt 세리프 steel 윤곽 섹션 번호 + 30pt 세리프 섹션명 + 1pt steel 룰. 인용은 슬레이트 패널 + 1pt steel 룰 + 24pt 세리프 풀쿼트 + 12pt 출처.

## 전환 (PPT)
subtle — 1pt 룰 라인과 콘텐츠가 200ms ease-out으로 짧게 페이드 인하는 정도만. 슬라이드·바운스·글로우 모션 금지.

## 하지 말 것
- 골드·따뜻한 강조 금지 — 차가운 cool steel만(골드는 다른 다크 IR·heritage 팩의 자리).
- 글로우·라디얼 그라디언트 금지(SaaS 다크 팩의 자리).
- 둥근 카드·이모지·클립아트 금지. 룰 라인을 두껍게 쓰지 말 것 — 1pt 유지.
- 헤딩에 산세리프만 쓰지 말 것 — 세리프 헤딩 + 산세리프 본문 혼합이 정체성.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.
- **거대 슬레이트 여백에 차트/표 하나만 두고 비우기 금지.** 정연함 ≠ 빈약 — 본문/차트/비교/타임라인 슬라이드는 1pt 룰로 구획된 모듈 3개 이상 + 출처 각주 + 페이지 번호.

## 상세 페이지 (7종)

### 01 · 표지 (cover)
딥 슬레이트 전면. 상단 11pt cool steel 대문자 라벨. 캔버스 중앙(상단 42%)에 30pt → 40pt로 키운 Newsreader 500 세리프 타이틀 중앙 정렬. 그 아래 0.15in에 1pt steel 룰 폭 3in + 그 아래 17pt 부제. 부제 아래에 도큐먼트 메타 행 — `PREPARED FOR` · `DATE` · `VERSION` 3개를 1pt 룰로 구분된 11pt 라벨/값 셀로. 하단 0.55in에 12pt 보조 텍스트 메타 + 페이지 번호 중앙 정렬. 표지는 절제 허용.

### 02 · 목차 (agenda)
상단 11pt steel 라벨 + 30pt 세리프 헤딩 + 1pt 룰. 본문 영역 좌측 7열에 `01`~`05` 목차 — steel 번호 + 세리프 16pt 항목명 + 그 아래 12pt 보조 텍스트 한 줄 설명 + 우측 끝 페이지 번호 + 1pt 룰 구분, 현재 섹션 좌측 1pt steel 룰(진행 인디케이터). 우측 5열에 슬레이트 패널 + 1pt 룰 — 본 덱 핵심 takeaway 3개를 steel 번호 미니 리스트로. 균형 여백.

### 03 · 핵심 본문 (body)
상단 steel 라벨 + 30pt 세리프 헤딩 + 1pt 룰 + 그 아래 12pt 보조 텍스트 리드 1줄. 본문 영역 좌측 6열에 17pt 본문 3~4줄(핵심 구절 steel) + 그 아래 3블록 분해(각 블록: steel 번호 + 14pt 600 미니헤더 + 14pt 근거 2개 + 메트릭 28pt). 우측 6열을 상하 2단 — 상단에 슬레이트 패널 보조 차트, 하단에 KPI 카드 2개 또는 콜아웃 모듈(좌측 1pt steel 룰 + 14pt 인사이트). 모듈 3개 이상. 하단 12pt 캡션 + 페이지 번호.

### 04 · 데이터 차트 (chart)
상단 steel 라벨 + 30pt 세리프 헤딩. 본문 영역 좌측 7열에 메인 세로 막대 차트 — 무채색 슬레이트 막대 + 강조 1막대 steel, 막대 폭:간격 3:2, 베이스라인 0, y축 주요 눈금 2~3개 0.5pt, 각 막대 14pt tabular 값 레이블. 차트 위 변곡점에 슬레이트 패널 콜아웃 2~3개(1pt steel 룰 + 가는 리더선 + 14pt 설명). 우측 5열을 상하 2단 — 상단에 보조 데이터 표(3~4행 1pt 룰 격자, 등폭 우정렬), 하단에 KPI 요약 스트립(`CAGR` · `합계` 2개 셀, 42pt Newsreader + 11pt 라벨). 범례 없이 직접 라벨링, 통화 단위 명기. 하단 좌측 12pt 출처·단위 각주 + 페이지 번호.

### 05 · 비교 매트릭스 (comparison)
상단 steel 라벨 + 30pt 세리프 헤딩 + 1pt 룰. 본문 영역 좌측 8열에 본격 1pt 룰 격자 비교 표 — 헤더 행 11pt 대문자 + 하단 1pt steel 룰, 행라벨 + 옵션 셀 4~6행 × 3~4열, 수치 셀 등폭 우정렬, 우세 셀 슬레이트 채움 + steel 텍스트. 우측 4열을 상하 2단 — 상단에 1pt 룰 십자축 2×2 매트릭스(steel 윤곽 원 데이터 포인트 복수), 하단에 슬레이트 패널 평결 콜아웃(1pt steel 룰 + 16pt 평결 1~2줄). 하단 12pt 출처 + 페이지 번호.

### 06 · 로드맵 타임라인 (timeline)
상단 steel 라벨 + 30pt 세리프 헤딩. 본문 영역 상단에 멀티트랙 수평 타임라인 — 0.75pt 베이스 날짜축, 페이즈 밴드(`Phase 1·2·3` 옅은 슬레이트 띠), 마일스톤 0.12in steel 윤곽 원(현재 시점만 steel 솔리드) + 사건 세리프 14pt 축 위 + 마일스톤 설명 12pt 축 아래, 'today' 마커 1pt steel 수직 점선. 단계별 1pt 룰 구획. 타임라인 아래에 단계별 산출물 미니 표(3~4행) + 콜아웃 모듈 1개. 하단 12pt 캡션 + 페이지 번호.

### 07 · 클로징 (closing)
딥 슬레이트 전면. 상단 11pt steel 라벨 + 30pt 세리프 헤딩 중앙 정렬. 본문 영역 중앙에 17pt 클로징 본문 2~3줄 + 1pt steel 룰 + 다음 단계 3개를 steel 번호 + 16pt 라벨 리스트로. 그 아래 핵심 기대 메트릭 2개 미니 스트립(42pt Newsreader + 11pt 라벨). 하단 0.55in에 12pt 보조 텍스트 컨택트 메타 + 페이지 번호 중앙 정렬.
