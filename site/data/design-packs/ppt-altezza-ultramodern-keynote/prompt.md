# Altezza 울트라모던 키노트 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. Altezza 울트라모던 키노트 — 사진·컬러 면을 각진 사선 클립 마스크(대각 12~18°)로 잘라 동적 긴장을 만들고, 거대 산세리프 헤드라인과 얇은 라벨이 강하게 대비하는 빽빽한 다크 에이전시 키노트. 강조는 electric mint 한 점.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 사진·컬러 면이 직사각형이 아니라 12~18° 각진 사선으로 잘려 있다 — clip-path 사선 마스크가 형태 정체성, (2) 거대 산세리프 헤드라인(800)과 얇은 라벨(300)이 같은 슬라이드에서 강하게 대비, (3) near-black 배경 + electric mint 한 점, 콘텐츠가 사선 분할선 기준으로 빽빽이 맞물린다. 둥근 모서리·발광 없음.

## 색
- 배경 near-black `#13141A`
- 패널 `#3A3C46`
- 강조 electric mint `#2EE6A6` — 강조 텍스트·사선 엣지 라인·차트 핵심 계열에만. 큰 면으로 절제해서만.
- 텍스트 `#F4F4F6`
- 얇은 라벨 `#9A9CA6`
- 강조색은 mint 1개뿐. 그라디언트·라디얼 글로우 금지.
- 통화 표기: 거대 수치는 `₩` 글리프 대신 `1,240억`·`KRW 1.24T`·`$1.2B` 식으로 표기(일부 폰트에서 ₩가 숫자와 겹친다).

## 타이포그래피
- 폰트: 전부 `Archivo`(대체 `Inter, Helvetica Neue, sans-serif`). 한글은 `Pretendard`.
- 거대 헤드라인: 56~72pt / Archivo 800 / 자간 -2% / 행간 1.0
- 슬라이드 헤딩: 32pt / Archivo 800 / 자간 -1%
- 얇은 라벨: 12pt / Archivo 300 / 자간 +12% / 대문자 / 색 얇은 라벨
- 본문: 17pt / Archivo 400 / 행간 1.4 / 슬라이드당 7줄 이하(dense 허용)
- KPI 거대 수치: 60pt / Archivo 800 / tabular numerals

## 레이아웃 / 그리드
- **비대칭(asymmetric) + dense.** 좌우 마진 각 0.55in, 상하 0.45in. 12열 그리드를 사선 분할선이 가로지른다.
- 슬라이드를 12~18° 사선으로 2~3 영역 분할 — 한쪽은 사진/컬러 클립 면, 다른 쪽은 콘텐츠.
- 콘텐츠는 사선 분할선 기준 비대칭 배치 — 텍스트 군집이 사선 가장자리에 맞물린다.
- **밀도 원칙(dense가 정체성):** 이 팩은 빽빽함이 정체성이다 — 거대 헤드라인 + 본문 + 라벨 + **데이터 모듈 3개 이상**이 사선 분할선 기준으로 맞물려 캔버스 90% 이상을 채운다. 핵심 메시지는 1개지만 사선 클립 패널·KPI 카드·차트·콜아웃이 빽빽이 공존한다. 거대 사선 면에 헤드라인 하나만 두는 것 금지(간지 예외).
- **모듈 좌표 컨벤션:** 14~16° 사선 분할선 기준 — 한쪽 영역에 헤딩+본문, 다른 쪽에 사선 클립 패널 모듈 묶음(KPI 카드 2~3개 사선 엣지 맞물림 + 차트 또는 표). 모듈 사이 사선 거터 0.18in.
- **사선 콜아웃:** 사선 클립 패널 `#3A3C46` + 1.5pt mint 사선 엣지, 안에 14pt 인사이트 1~2줄 + 12pt 라벨체 라벨. 차트·본문 옆에 1개 맞물려 배치.

## 형태 / 질감
- 사진·컬러 면은 직사각형 금지 — 12~18° 각진 사선 clip-path 마스크 필수.
- 모서리 반경 0px(직각·사선만, 둥근 클립 금지). 그림자·발광 없음.
- 사선 엣지 라인은 1.5pt mint 또는 흰 라인으로 강조 가능.
- 패널 `#3A3C46` 채움. 아이콘은 1.5pt 가는 라인 단색, 각진.

## 차트·데이터 시각화 (울트라모던 차트 — 다크 + mint 한 점)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 차트도 사선·각진 미감을 입는다.
- **데이터 색:** 막대·선 기본은 패널 그레이 `#5A5C66`(연) / `#9A9CA6`(진). 강조할 1개만 electric mint `#2EE6A6` 솔리드. 무지개 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 0px(각진). 베이스라인 0(잘린 y축 금지). 막대 상단을 사선으로 자르는 옵션(12~18°) — 강조 막대만.
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 2~3개 0.5pt `#3A3C46`). 차트 테두리 박스 제거. x축선 0.75pt `#9A9CA6`.
- **값 레이블:** 막대·꼭짓점에 직접 표기, 14pt Archivo 600 tabular `#F4F4F6`. 범례 박스 금지 — 직접 라벨링.
- **출처:** 차트 하단 좌측 11pt Archivo `#9A9CA6` 출처·단위 각주.
- **타입 매칭:** 비교=세로 막대, 추세=2pt 폴리라인(mint, 면적 채움 없음 또는 mint 10% 사선 클립 면적), 비중=도넛 1개(조각 3개 이하). 파이 다중·3D 금지.

## 다이어그램·컴포넌트 (사선 클립 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며 **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 각진 패널(반경 0px), 사선 12~18° 엣지로 잘림, 커넥터는 2pt 각진 라인(셰브론 화살촉), 단계 번호는 사선 클립된 작은 mint 배지, 강조는 mint 텍스트·1.5pt mint 사선 엣지.
- **프로세스 플로우:** 좌→우 사선 평행사변형 노드 4~5단계(12~18° 기울임) — 패널 채움, 노드 사이 2pt 각진 셰브론. 각 노드에 작은 mint 단계 배지(사선 클립). 현재 단계만 1.5pt mint 사선 엣지.
- **타임라인:** 사선 12~18° 기울인 축. 마일스톤은 0.14in 각진 다이아몬드(현재 시점만 mint 솔리드). 날짜 라벨 12pt 라벨체.
- **비교(사선 분할):** 슬라이드를 12~18° 사선으로 2~3 영역 분할 — 각 영역에 헤딩 + 본문 + 수치. 사선 분할선이 열 구분선, 1.5pt mint 엣지 라인.
- **매트릭스 2×2:** 축을 살짝 사선(8~12°) 기울인 2×2 — 0.75pt 패널 십자축. 데이터 포인트는 0.16in 각진 마름모(핵심만 mint 솔리드). 사분면 라벨 14pt.
- **계층/퍼널:** 사선 클립된 폭 비례 적층 — 각 단이 12~18° 평행사변형, 패널 명도 단계, 핵심 단만 mint. 레벨 라벨 우측.
- **KPI·스탯 카드:** 사선 클립된 패널 카드(12~18° 한쪽 모서리 잘림), 12pt 라벨체 라벨 + 60pt Archivo 800 수치 + 14pt mint 델타. 카드 3~4개, 사선 엣지가 맞물림.
- **목차/섹션 디바이더/인용:** 목차는 사선 클립 mint 번호 배지 + 17pt 항목명. 디바이더는 사선 클립된 거대 컬러/사진 면 + 72pt 헤드라인. 인용은 사선 클립 패널 + 1.5pt mint 사선 엣지 + 28pt 800 풀쿼트 + 12pt 출처.

## 전환 (PPT)
snappy — 사선 클립 면이 한쪽에서 사선 방향으로 빠르게 슬라이드 인(140~180ms ease-out), 헤드라인은 100ms 늦게 따라 들어옴. 절도 있고 빠르게, 바운스 없음.

## 하지 말 것
- 둥근 모서리·둥근 클립 금지 — 각진 사선 12~18°만.
- 글로우·라디얼 그라디언트 금지(다른 다크 SaaS 팩의 자리).
- 사진을 직사각형 그대로 쓰지 말 것 — 사선 clip-path 마스크 필수.
- electric mint를 큰 면으로 도배하지 말 것 — 강조 텍스트·사선 엣지·차트 1계열에만.
- 이모지·클립아트 금지. 대칭 중앙 정렬로 회귀 금지 — 비대칭이 정체성.
- 차트 회귀: 3D, 무지개색, 격자선 과다, 범례 박스, 잘린 y축, 출처 누락.
- **거대 사선 면에 헤드라인 하나만 두고 비우기 금지(간지 예외).** dense가 정체성 — 본문/차트/KPI/비교 슬라이드는 사선 모듈 3개 이상으로 빽빽이 채운다. 모든 본문성 슬라이드에 출처 각주 + 페이지 번호.

## 상세 페이지 (6종)

### 01 · 표지 (사선 클립) (cover)
near-black 배경. 슬라이드를 14° 사선으로 분할 — 우측 60%는 사선 클립된 컬러/사진 면, 좌측 40%는 콘텐츠. 좌측에 12pt 대문자 라벨(라벨체 300) + 그 아래 거대 72pt Archivo 800 타이틀 2~3줄 + 17pt 부제. 좌측 하단에 사선 클립 메타 배지 행(`PROJECT` · `DATE` · `VERSION` 12pt 라벨체). 사선 분할 엣지에 1.5pt mint 라인. 우하단 모서리 12pt 페이지 메타. 표지는 비교적 절제 허용.

### 02 · 섹션 간지 (section-divider)
near-black 전면. 슬라이드 전체에 16° 사선 클립된 거대 컬러 면(우상→좌하). 그 위에 거대 72pt Archivo 800 섹션명 + 작은 mint 사선 클립 섹션 번호 배지. 사선 면 하단에 이 섹션 항목 3개를 사선 클립 미니 배지(mint 번호 + 12pt 라벨)로. 사선 엣지 1.5pt mint 라인.

### 03 · 핵심 본문 (body)
near-black 배경. 좌측 영역에 12pt 라벨 + 32pt 800 헤딩 + 17pt 리드 1줄 + 3컬럼 분해(각 컬럼: mint 번호 + 14pt 600 미니헤더 + 14pt 근거 2개 + 컬럼 하단 메트릭 20pt 800). 우측에 14° 사선 클립 패널 묶음 — 보조 막대 차트 또는 사진 면 + 그 아래 사선 콜아웃 1개(1.5pt mint 사선 엣지 + 14pt 인사이트). 사선 분할선 기준 비대칭 dense 배치. 하단 11pt 출처/캡션 + 페이지 번호. 모듈 4개 이상.

### 04 · 사선 분할 비교 (comparison)
near-black 배경. 슬라이드를 16° 사선으로 좌우 두 영역 분할 — 각 영역에 옵션 헤딩(32pt 800) + 본격 비교 항목 4~6행(행라벨 + 수치, 사선 클립 행 카드, 우세 셀 mint). 사선 분할선이 열 구분, 1.5pt mint 사선 엣지 라인. 본문 하단에 사선 클립 평결 패널(mint 사선 엣지 + 종합 평결 메트릭 20pt 800 + 14pt 평결 1줄). 하단 11pt 출처 + 페이지 번호.

### 05 · KPI 대시보드 (kpi)
near-black 배경. 32pt 800 헤딩 + 12pt 라벨. 본문 영역에 사선 클립된 패널 KPI 카드 4~6개(각 12~18° 한쪽 모서리 잘림) 그리드 — 각 카드: 12pt 라벨체 라벨 + 60pt Archivo 800 수치 + 14pt mint 델타 + 가는 mint 미니 스파크라인 + 12pt 맥락 1줄. 카드 사선 엣지가 서로 맞물려 빽빽이(dense). 그 옆에 보조 차트(세로 막대 또는 mint 추이 라인) + 사선 콜아웃 1개. 하단 11pt 출처 + 페이지 번호.

### 06 · 클로징 (closing)
near-black 전면. 18° 사선 클립된 거대 컬러 면 + 거대 56pt Archivo 800 클로징 헤드라인. 그 아래 12pt 라벨체 부제 + 다음 단계 3개를 사선 클립 미니 배지(mint 번호 + 14pt 라벨)로. 사선 엣지 1.5pt mint. 우하단 모서리 12pt 컨택트 메타 + 페이지 번호.
